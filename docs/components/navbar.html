Navbar Component

상단 내비게이션 바는 브랜드, 페이지 링크, 액션 버튼을 통합해 주요 탐색을 제공합니다. 템플릿을 기준으로 다양한 변형과 접근성 가이드를 정리했습니다.

Basic Usage

Default Navbar

브랜드 영역, 1차 메뉴, 보조 액션을 포함한 기본 구조입니다. data-navbar 속성이 모바일 토글과 드롭다운 제어를 초기화합니다.

Overview Pricing Docs Support
HTML 코드 보기 
<nav class="navbar" data-navbar>
    <div class="navbar__container">
        <a href="#" class="navbar__brand">Brand</a>
        <div class="navbar__menu">
            <a href="#" class="navbar__link navbar__link--active">Home</a>
            <a href="#" class="navbar__link">Features</a>
        </div>
        <div class="navbar__actions">...</div>
        <button type="button" class="navbar__toggle" data-navbar-toggle aria-label="Toggle navigation">...</button>
    </div>
</nav>
JavaScript Example 
document.addEventListener('DOMContentLoaded', () => {
    BRICKS.Navbar.init();

    const mainNavbar = document.querySelector('.navbar');
    mainNavbar?.addEventListener('navbarMobileOpen', (event) => {
        console.log('Mobile menu opened', event.detail.navbar);
    });
    mainNavbar?.addEventListener('navbarMobileClose', (event) => {
        console.log('Mobile menu closed', event.detail.navbar);
    });
});

Accessibility

ARIA Attributes

내비게이션 역할과 드롭다운 항목의 상태를 명확히 전달해야 합니다.

  • 내비게이션 전체에 role="navigation" 또는 aria-label을 지정합니다.
  • 드롭다운 토글 버튼에는 aria-expanded와 aria-controls를 동기화합니다.
  • 모바일 토글은 aria-label 또는 aria-expanded를 포함합니다.
  • 아이콘 버튼은 적절한 aria-label을 가지도록 합니다.

Keyboard Support

Key Description
Tab 브랜드, 메뉴 항목, 액션 버튼 순으로 포커스가 이동합니다.
Enter / Space 메뉴 항목이나 드롭다운 토글을 활성화합니다.
Esc 열려 있는 드롭다운이나 모바일 메뉴를 닫습니다.
ArrowDown 드롭다운 내부에서 다음 항목으로 이동합니다.

Usage Guidelines

Do's and Don'ts

✅ Do

  • 브랜드 영역은 항상 좌측 상단에 고정합니다.
  • 5개 이하의 최상위 메뉴만 배치해 인지 부하를 줄입니다.
  • 모바일에서는 햄버거 토글과 전체 화면 메뉴로 전환합니다.
  • 드롭다운 토글에 키보드와 스크린 리더 접근성을 제공합니다.

❌ Don't

  • 중요한 액션을 드롭다운 깊숙이 숨기지 않습니다.
  • 토글 버튼에 대체 텍스트를 제공하지 않는 것은 피합니다.
  • 스크롤 시 네비게이션이 사라져 길찾기가 어려워지지 않도록 합니다.
  • 데스크톱과 모바일에서 서로 다른 메뉴 항목을 제공하지 않습니다.
