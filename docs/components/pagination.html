Pagination Component

페이지네이션은 목록이나 테이블의 페이지 이동을 돕는 핵심 내비게이션 패턴입니다. 템플릿을 기준으로 구조화하여 기본 사용법과 변형, 접근성 가이드라인을 한눈에 정리했습니다.

Basic Usage

Default Pagination

좌우 화살표와 페이지 버튼을 제공하는 가장 일반적인 형태입니다. data-pagination 속성을 추가하면 자동으로 상호작용이 연결됩니다.

JavaScript Example 
document.addEventListener('DOMContentLoaded', () => {
    BRICKS.Pagination.init();

    const projectPagination = document.querySelector('[aria-label="Project list navigation"]');
    projectPagination?.addEventListener('pageChange', (event) => {
        console.log('페이지 변경:', event.detail.page);
    });

    const dynamicPagination = document.querySelector('#analytics-pagination');
    if (dynamicPagination) {
        const activeLink = dynamicPagination.querySelector('.pagination__link--active');
        const currentPage = activeLink ? parseInt(activeLink.getAttribute('data-page'), 10) || 1 : 1;
        BRICKS.Pagination.generatePages(dynamicPagination, currentPage);
        BRICKS.Pagination.updateState(dynamicPagination);
    }
});

Accessibility

ARIA Attributes

페이지네이션은 내비게이션 역할을 가지므로 명확한 레이블과 현재 상태 전달이 중요합니다.

  • aria-label로 내비게이션 목적을 설명합니다.
  • aria-current="page"는 현재 페이지를 스크린 리더에 전달합니다.
  • aria-disabled는 이전/다음 버튼이 사용 불가함을 명시합니다.
  • 키보드 순환을 위해 버튼은 모두 tabindex를 유지합니다.

Keyboard Support

Key Description
Tab 페이지 버튼과 이전/다음 컨트롤을 순차적으로 포커스합니다.
Shift + Tab 역방향으로 포커스를 이동합니다.
Enter / Space 포커스된 페이지 링크를 활성화합니다.
Home / End 첫 번째 또는 마지막 페이지 링크로 이동하도록 확장 구현할 수 있습니다.
페이지 변경 이벤트 
const analyticsPagination = document.querySelector('#analytics-pagination');
analyticsPagination?.addEventListener('pageChange', (event) => {
    const { page, previousPage } = event.detail;
    console.log(`Changed from ${previousPage} to ${page}`);
});

Method Parameters Description

Usage Guidelines

Do's and Don'ts

✅ Do

  • 현재 페이지 범위를 표시해 사용자가 위치를 쉽게 파악하도록 돕습니다.
  • 페이지 수가 많다면 엘립시스와 총 페이지 정보를 함께 제공합니다.
  • 비활성 버튼에는 aria-disabled와 tabindex 처리를 함께 적용합니다.
  • 모바일에서는 적은 수의 버튼만 표시하고 나머지는 숨깁니다.

❌ Don't

  • 페이지 버튼을 10개 이상 한 번에 노출해 인지 부하를 늘리지 않습니다.
  • 이전/다음 버튼을 제거해 탐색 경로를 제한하지 않습니다.
  • 페이지 이동 시 스크롤 위치를 유지하지 않거나 콘텐츠를 즉시 업데이트하지 않는 것은 피합니다.
  • 아이콘만 사용해 텍스트 레이블을 생략하면 접근성이 떨어집니다.
