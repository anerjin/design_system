Accessibility

Native Radio Accessibility

Radio 컴포넌트는 Native HTML을 사용하여 자동으로 접근성을 제공합니다:

  • Native 시멘틱 - <input type="radio">는 이미 radio 역할을 가짐
  • 암묵적 라벨 연결 - <label>로 감싼 구조로 자동 연결
  • 그룹화 - name 속성으로 자동 그룹화
  • 상태 관리 - checked와 disabled 속성으로 충분
  • 키보드 내비게이션 - 브라우저가 자동으로 화살표키 내비게이션 지원
  • 포커스 관리 - Native roving tabindex 자동 처리

💡 Tip: Native radio는 JavaScript 없이도 완벽한 접근성을 제공합니다. 추가 ARIA 속성은 불필요하며 오히려 혼란을 야기할 수 있습니다.

Keyboard Navigation

완전한 키보드 내비게이션을 지원합니다:

키 동작
Tab 라디오 그룹으로 포커스 이동
Arrow Up/Left 이전 라디오로 이동 및 선택
Arrow Down/Right 다음 라디오로 이동 및 선택
Home 첫 번째 라디오로 이동 및 선택
End 마지막 라디오로 이동 및 선택
Space / Enter 현재 라디오 선택

Focus Management

  • Native roving tabindex - 라디오 그룹당 하나의 Tab Stop
  • 자동 포커스 관리 - 선택된 라디오 또는 첫 번째 라디오가 Tab 포커스를 받음
  • 화살표키 내비게이션 - 방향키로 그룹 내 이동 및 자동 선택 (브라우저 기본 동작)
  • 비활성 항목 처리 - disabled 라디오는 자동으로 건너뜀 (브라우저 기본 동작)

Screen Reader Support

Native radio의 우수한 스크린 리더 지원:

  • 자동 상태 알림 - Native radio가 선택됨/해제됨 상태를 자동으로 전달
  • 암묵적 라벨 연결 - <label>로 감싼 구조로 라벨 자동 읽기
  • 그룹 인식 - name 속성으로 그룹화된 라디오 인식
  • 시각적 요소 숨김 - aria-hidden="true"로 장식 요소 제외
  • 키보드 내비게이션 - 화살표키로 그룹 내 이동 지원

Implementation Example

코드 보기 
<!-- Simple and Accessible Radio Group (Native HTML) -->
<fieldset class="radio-group">
    <legend>Choose your option:</legend>

    <label class="radio">
        <input type="radio"
               class="radio__input"
               name="options"
               value="option1"
               checked>
        <span class="radio__circle" aria-hidden="true">
            <span class="radio__dot"></span>
        </span>
        <span class="radio__label">
            <strong>Option 1</strong>
            <span class="radio__description">
                Description for option 1
            </span>
        </span>
    </label>

    <label class="radio">
        <input type="radio"
               class="radio__input"
               name="options"
               value="option2">
        <span class="radio__circle" aria-hidden="true">
            <span class="radio__dot"></span>
        </span>
        <span class="radio__label">
            Option 2
        </span>
    </label>

    <label class="radio">
        <input type="radio"
               class="radio__input"
               name="options"
               value="option3"
               disabled>
        <span class="radio__circle" aria-hidden="true">
            <span class="radio__dot"></span>
        </span>
        <span class="radio__label">
            Option 3 (Disabled)
        </span>
    </label>
</fieldset>

<script>
// Native JavaScript로 간단하게 제어
const radios = document.querySelectorAll('input[name="options"]');

// 변경 감지
radios.forEach(radio => {
    radio.addEventListener('change', (e) => {
        console.log('선택된 값:', e.target.value);
    });
});

// 프로그래밍적으로 선택
document.querySelector('input[name="options"][value="option2"]').checked = true;

// 현재 선택된 값 가져오기
const selected = document.querySelector('input[name="options"]:checked')?.value;
</script>
