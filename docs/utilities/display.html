Usage Guidelines

Do's and Don'ts

✅ Do

  • 레이아웃 전환 전에 의미론적 HTML 구조를 먼저 정의합니다.
  • 반응형 display 클래스를 조합해 필요한 뷰포트에만 컴포넌트를 노출합니다.
  • 스크린 리더 접근성을 위해 `sr-only`와 함께 사용하여 정보를 완전히 숨기지 않도록 합니다.
  • 플렉스/그리드 전환은 재사용 가능한 패턴으로 캡슐화해서 유지보수를 쉽게 합니다.

❌ Don't

  • 동일한 요소에 여러 display 클래스를 중첩하여 우선순위 충돌을 만들지 않습니다.
  • 콘텐츠를 숨길 때 `visibility: hidden` 대신 `d-none`만 사용하는 경우 포커스 이동 가능성을 확인합니다.
  • JS로 display를 토글할 때 클래스와 인라인 스타일을 혼용하지 않습니다.
  • 랜더링 이슈 없이도 단순히 여백 조정을 위해 display 속성을 변경하지 않습니다.
