Accordion Component

아코디언은 관련된 정보를 접고 펼치는 패턴으로, 한 화면에서 긴 컨텐츠를 효율적으로 정리할 수 있도록 돕습니다. 템플릿 구조를 기반으로 기본 사용법부터 변형, 접근성 가이드까지 일관되게 정리했습니다.

Basic Usage

Default Accordion

동시에 하나의 패널만 펼쳐지는 기본 아코디언 패턴입니다. data-accordion 속성을 지정하면 스크립트가 자동으로 초기화합니다.

모든 컴포넌트, 디자인 토큰, 우선 지원, 그리고 맞춤형 테마 기능이 포함됩니다.

네, 라이센스에 명시된 범위 내에서 기업 및 상업 프로젝트에 활용할 수 있습니다.

디자인 시스템 팀에 피드백 양식을 제출하면 우선순위와 일정을 검토해 로드맵에 반영합니다.

HTML 코드 보기 
<div class="accordion" data-accordion>
    <div class="accordion__item accordion__item--open">
        <button type="button" class="accordion__header accordion__header--active">
            <span>Panel title</span>
            <svg class="accordion__icon" aria-hidden="true">...</svg>
        </button>
        <div class="accordion__content accordion__content--open">
            <div class="accordion__body">
                <p>Panel content</p>
            </div>
        </div>
    </div>
</div>
JavaScript Example 
document.addEventListener('DOMContentLoaded', () => {
    BRICKS.Accordion.init();

    const faqAccordion = document.querySelector('#product-faq');
    faqAccordion?.addEventListener('accordionToggle', (event) => {
        console.log('Accordion state changed:', event.detail);
    });
});

Variations

Multiple Panels

여러 패널을 동시에 펼치고 싶다면 data-accordion-multiple="true" 속성을 사용합니다.

진행 중인 프로젝트의 하이라이트를 정리합니다.

다음 마일스톤과 담당자를 빠르게 확인할 수 있습니다.

data-accordion-multiple

Flush Layout

카드 경계 없이 섹션 내부에 자연스럽게 배치할 때 .accordion--flush를 사용합니다.

결제 수단을 관리하고 청구서를 다운로드합니다.

월별 청구 내역과 결제 상태를 확인하세요.

.accordion--flush

Icon Left

아이콘을 타이틀 왼쪽으로 배치하려면 .accordion--icon-left를 추가합니다.

2단계 인증, 세션 제어, 감사 로그 등을 설정합니다.

역할 기반 권한을 정의하여 멤버 접근을 제어할 수 있습니다.

.accordion--icon-left

Sizes

Small

보조 정보나 사이드바에 적합한 컴팩트 사이즈입니다.

상태, 태그, 담당자 필터를 설정하세요.

팀이 공유하는 보드를 빠르게 전환합니다.

.accordion--sm

Default

대부분의 페이지에서 사용하는 기본 사이즈입니다.

최근 활동과 주요 공지 사항을 확인합니다.

주요 팀 공지와 리소스를 모아둔 영역입니다.

Default size

Large

넉넉한 여백으로 긴 텍스트를 읽기 편하게 제공합니다.

컴포넌트 사용 원칙과 시각적 제약을 정리한 문서입니다.

WCAG 준수를 위한 검토 항목과 테스트 시나리오를 제공합니다.

.accordion--lg

States

Interactive States

hover, focus, expand 상태를 사전에 검토해 접근성과 일관성을 유지하세요.

Collapsed

닫힌 상태에서는 aria-expanded="false"를 유지합니다.

Expanded

확장된 패널은 콘텐츠 높이에 맞게 자동으로 늘어납니다.

aria-expanded="true"와 애니메이션을 확인하세요.

Focus

키보드 포커스 링은 명확하게 표시되어야 합니다.

Disabled

비활성 상태는 클릭/키보드 이벤트를 차단합니다.

Accessibility

ARIA Attributes

스크린 리더가 패널 상태와 제목을 정확히 전달할 수 있도록 다음 속성을 제공합니다.

  • role="button"과 tabindex="0"로 헤더를 포커스 가능하게 만듭니다.
  • aria-expanded는 패널의 열린 상태를 표시합니다.
  • aria-controls는 헤더와 콘텐츠 영역을 연결합니다.
  • aria-disabled는 상호작용이 불가능한 패널을 알립니다.

Keyboard Support

Key Description
Tab 다음 아코디언 헤더로 포커스를 이동합니다.
Shift + Tab 이전 헤더로 포커스를 이동합니다.
Enter / Space 현재 포커스된 패널을 토글합니다.
ArrowUp / ArrowDown 이전 또는 다음 헤더로 이동합니다.
Home 첫 번째 헤더로 빠르게 이동합니다.
End 마지막 헤더로 이동합니다.
접근성 이벤트 예시 
const settingsAccordion = document.querySelector('#settings-accordion');
settingsAccordion?.addEventListener('accordionToggle', (event) => {
    const { header, isOpen } = event.detail;
    header.setAttribute('aria-expanded', isOpen.toString());
});

Usage Guidelines

Do's and Don'ts

✅ Do

  • 패널 제목은 질문형 또는 명확한 문장으로 작성합니다.
  • 긴 문서는 섹션 단위로 나눠 스캔이 쉽게 유지되도록 합니다.
  • 시각적 인디케이터와 aria-expanded 값을 동기화합니다.
  • 여러 패널을 동시에 열어야 한다면 data-accordion-multiple을 사용합니다.

❌ Don't

  • 아코디언 안에 또 다른 아코디언을 중첩해서 사용하지 않습니다.
  • 패널 열림 상태를 초기화 이후 JavaScript에서 강제로 변경하지 않습니다.
  • 헤더를 링크로 대체하거나 버튼 역할을 제거하지 않습니다.
  • 접근성 속성 없이 시각적 장식만으로 상태를 표현하지 않습니다.
