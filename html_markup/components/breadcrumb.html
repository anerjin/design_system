Breadcrumb Component

브레드크럼은 사용자가 현재 위치와 상위 경로를 파악하도록 돕는 계층형 내비게이션입니다. 템플릿을 기준으로 다양한 구성을 정리했습니다.

Basic Usage

Default Breadcrumb

기본 브레드크럼은 순서형 목록과 링크로 구성되며, 마지막 항목은 현재 페이지로 표시합니다.

  1. Home
  2. Products
  3. Analytics
HTML 코드 보기 
<nav aria-label="Breadcrumb">
    <ol class="breadcrumb" data-breadcrumb>
        <li class="breadcrumb__item">
            <a href="#" class="breadcrumb__link">Home</a>
        </li>
        <li class="breadcrumb__item">
            <a href="#" class="breadcrumb__link">Products</a>
        </li>
        <li class="breadcrumb__item breadcrumb__item--active" aria-current="page">
            Analytics
        </li>
    </ol>
</nav>

Accessibility

ARIA Attributes

브레드크럼은 내비게이션 정보이므로 의미를 명확히 전달하는 속성이 필요합니다.

  • aria-label로 내비게이션 목적을 설명합니다.
  • aria-current="page"는 현재 위치를 스크린 리더에 알립니다.
  • 링크 순서는 문서 구조와 일치하도록 유지합니다.
  • 구분자는 CSS ::before로 처리해 스크린 리더에 반복되지 않도록 합니다.

Keyboard Support

Key Description
Tab 각 링크를 순차적으로 포커스합니다.
Shift + Tab 역방향으로 경로를 탐색합니다.
Enter / Space 선택된 경로로 이동합니다.

API Reference

Properties & Classes

Class / Attribute Description Values
.breadcrumb 브레드크럼 루트 목록 필수
data-breadcrumb 공통 스타일 초기화를 위한 데이터 속성 필수
.breadcrumb__item 각 경로 항목 필수
.breadcrumb__item--active 현재 페이지 표시 단일
.breadcrumb__link 상위 경로 링크 필수
.breadcrumb--{separator} 구분자 변경 slash, arrow, chevron, dot, pipe
.breadcrumb--sm, .breadcrumb--lg 사이즈 변형 sm, lg
.breadcrumb--responsive, .breadcrumb--truncate 모바일 최적화 및 글자 수 제한 responsive, truncate

Usage Guidelines

Do's and Don'ts

✅ Do

  • 항상 최상위 링크부터 현재 페이지까지의 전체 경로를 포함합니다.
  • 링크 텍스트는 짧고 명확하게 작성합니다.
  • 모바일에서는 경로를 접거나 드롭다운으로 대체합니다.
  • 현재 위치는 비활성화하고 aria-current를 지정합니다.

❌ Don't

  • 한 화면에 브레드크럼을 두 개 이상 배치하지 않습니다.
  • 현재 페이지를 링크로 노출해 다시 로드하게 만들지 않습니다.
  • 단일 단계 페이지에서 불필요하게 브레드크럼을 사용하지 않습니다.
  • 구분자를 텍스트로 직접 작성해 스크린 리더에 중복 안내하지 않습니다.
