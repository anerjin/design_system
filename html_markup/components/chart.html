Chart Container Sizes

Size Variations

Charts can be displayed in various container sizes:

  • .chart-container - Default size (400px height)
  • .chart-container--small - Small size (300x300px, centered)
  • .chart-container--medium - Medium size (500x400px, centered)
  • .chart-container--large - Large size (500px height)
  • .chart-container--xl - Extra large (600px height)

JavaScript Implementation

Basic Chart Setup

JavaScript 코드 보기 
// Initialize chart with dark mode support
const ctx = document.getElementById('myChart');
const isDark = document.documentElement.getAttribute('data-theme') === 'dark';

const chart = new Chart(ctx, {
    type: 'line',
    data: {
        labels: ['Jan', 'Feb', 'Mar', 'Apr', 'May', 'Jun'],
        datasets: [{
            label: 'Sales',
            data: [12, 19, 15, 25, 22, 30],
            borderColor: isDark ? '#FFFFFF' : '#000000',
            backgroundColor: isDark ? 'rgba(255,255,255,0.1)' : 'rgba(0,0,0,0.1)'
        }]
    },
    options: {
        responsive: true,
        maintainAspectRatio: false,
        plugins: {
            legend: {
                labels: {
                    color: isDark ? '#FFFFFF' : '#000000'
                }
            }
        },
        scales: {
            x: {
                ticks: { color: isDark ? '#9CA3AF' : '#6B7280' },
                grid: { color: isDark ? '#374151' : '#E5E7EB' }
            },
            y: {
                ticks: { color: isDark ? '#9CA3AF' : '#6B7280' },
                grid: { color: isDark ? '#374151' : '#E5E7EB' }
            }
        }
    }
});

Dark Mode Support

Automatic Theme Detection

자동 테마 감지

모든 차트는 테마 변경을 자동으로 감지하여 색상을 업데이트합니다. Light 모드에서는 검은색, Dark 모드에서는 흰색으로 표시됩니다.

Features

주요 기능

  • Chart.js 기반의 강력한 차트 라이브러리
  • 완벽한 다크 모드 지원
  • 반응형 디자인
  • 다양한 차트 타입 지원
  • 애니메이션 효과
  • 인터랙티브 툴팁

  • Bar Chart - 카테고리 비교
  • Doughnut Chart - 비율 표시

  • Radar Chart - 다차원 비교
  • Mixed Chart - 복합 차트
