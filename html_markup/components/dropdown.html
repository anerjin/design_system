Dropdown Components

DOI INC Design System의 드롭다운 컴포넌트입니다. 사용자가 선택할 수 있는 옵션 목록을 제공하는 다양한 변형과 기능을 지원합니다.

API Reference

Classes & Properties

Dropdown Classes

Class Description Values
.dropdown Base dropdown container Required
.dropdown__toggle Dropdown trigger button Button element
.dropdown__menu Dropdown menu container Menu content
.dropdown__item Menu item Link or button
.dropdown__divider Menu divider line Separator
.dropdown__header Menu section header Text content
.dropdown--{size} Dropdown size sm, lg
.dropdown--{direction} Menu direction dropup, dropright
.dropdown--select Select mode Updates button text
.dropdown--fixed Fixed position mode Escapes overflow
.dropdown--open Open state (JS) Shows menu

Menu Classes

Class Description Values
.dropdown__menu--{align} Menu alignment right, center
.dropdown__item--{state} Item state active, disabled
.dropdown__item-icon Item with icon Icon + text layout

Accessibility

Keyboard Navigation

키 동작 설명
Enter / Space 토글 버튼에서 드롭다운 메뉴를 열거나 닫습니다
ArrowDown 토글 버튼에서 드롭다운을 열고 첫 번째 아이템으로 포커스 이동
ArrowDown 메뉴 아이템에서 다음 아이템으로 포커스 이동
ArrowUp 메뉴 아이템에서 이전 아이템으로 포커스 이동
Home 메뉴 아이템에서 첫 번째 아이템으로 포커스 이동
End 메뉴 아이템에서 마지막 아이템으로 포커스 이동
Enter / Space 메뉴 아이템에서 아이템 선택 및 드롭다운 닫기
Escape 언제든지 드롭다운을 닫고 토글 버튼으로 포커스 이동
Tab 메뉴 아이템에서 드롭다운을 닫고 다음 요소로 포커스 이동

ARIA Attributes

속성 요소 설명
aria-expanded 토글 버튼 드롭다운 메뉴의 열림/닫힘 상태 표시
aria-haspopup 토글 버튼 팝업 메뉴가 있음을 표시
aria-controls 토글 버튼 제어하는 메뉴 요소의 ID 참조
role="menu" 드롭다운 메뉴 메뉴 역할 정의
role="menuitem" 메뉴 아이템 메뉴 항목 역할 정의
aria-labelledby 드롭다운 메뉴 메뉴를 설명하는 토글 버튼 ID 참조
aria-selected 메뉴 아이템 선택된 아이템 표시
aria-disabled 메뉴 아이템 비활성화된 아이템 표시
tabindex 메뉴 아이템 키보드 포커스 관리 (-1: 프로그램적으로만, 0: 포커스 가능)

Usage Guidelines

Do's and Don'ts

✅ Do

  • 명확한 라벨 사용
  • 논리적인 항목 순서 유지
  • 적절한 아이콘으로 시각적 단서 제공
  • 키보드 탐색 지원
  • 선택된 항목 명확히 표시

❌ Don't

  • 너무 많은 옵션 제공 금지 (7±2 규칙)
  • 중첩된 드롭다운 과도 사용 금지
  • 모바일에서 작은 타겟 영역 금지
  • 자동으로 닫히는 타이밍 너무 빠르게 설정 금지
  • 중요한 액션만 드롭다운에 숨기기 금지
