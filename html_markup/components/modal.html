Modal Components

DOI INC Design System의 모달 다이얼로그 컴포넌트입니다. 오버레이 형태로 표시되어 사용자와 상호작용하는 다양한 변형과 기능을 지원합니다.

Basic Usage

Default Modal

코드 보기 
<div class="modal" id="modal-basic" role="dialog" aria-modal="true" aria-labelledby="modal-title" aria-describedby="modal-body">
    <div class="modal__dialog">
        <div class="modal__header">
            <h3 class="modal__title" id="modal-title">Modal Title</h3>
            <button type="button" class="modal__close" aria-label="Close modal">×</button>
        </div>
        <div class="modal__body" id="modal-body">
            <p>Modal content goes here</p>
        </div>
        <div class="modal__footer">
            <button class="btn btn--secondary">Cancel</button>
            <button class="btn btn--primary">Confirm</button>
        </div>
    </div>
</div>

API Reference

Classes & Properties

Modal Classes

Class Description Values
.modal Base modal container Required
.modal--open Show modal (applied via JS) Visibility state
.modal--centered Center modal vertically Position modifier
.modal--static Static backdrop (no close on click) Interaction modifier

Dialog Classes

Class Description Max Width
.modal__dialog Modal dialog container 500px
.modal__dialog--sm Small dialog 400px
.modal__dialog--lg Large dialog 800px
.modal__dialog--xl Extra large dialog 1200px
.modal__dialog--fullscreen Full screen dialog 100%
.modal__dialog--scrollable Scrollable body content -

Modal Elements

Class Description Usage
.modal__header Modal header section Optional
.modal__title Modal title text Header content
.modal__close Close button Interactive element
.modal__body Modal body content Main content
.modal__footer Modal footer section Optional

Accessibility

ARIA Attributes

  • role="dialog" - 다이얼로그 역할 정의
  • aria-modal="true" - 모달 다이얼로그임을 명시
  • aria-labelledby - 모달 제목과 연결
  • aria-describedby - 모달 설명과 연결
  • aria-hidden="true" - 숨겨진 모달 상태

Keyboard Navigation

  • Tab - 포커스 이동
  • Shift + Tab - 역방향 포커스 이동
  • Escape - 모달 닫기
  • Enter - 기본 액션 실행

Best Practices

  • 모달 열릴 때 첫 번째 포커스 가능 요소로 포커스 이동
  • 모달 내에서만 포커스 순환 (Focus Trap)
  • 모달 닫힐 때 트리거 요소로 포커스 복귀
  • 배경 클릭으로 닫기 옵션 제공 (static 제외)
  • 명확한 닫기 버튼 제공

Usage Guidelines

Do's and Don'ts

✅ Do

  • 중요한 사용자 상호작용에 사용
  • 명확한 제목과 설명 제공
  • 적절한 크기 선택
  • 키보드 탐색 지원
  • 모달 내용은 간결하게 유지

❌ Don't

  • 과도한 모달 중첩 금지
  • 자동으로 열리는 모달 최소화
  • 복잡한 폼은 페이지로 대체
  • 중요 정보만 모달에 표시 금지
  • 모바일에서 과도한 크기 사용 금지
