Tabs Component

DOI INC Design System의 탭 컴포넌트는 콘텐츠를 구조적으로 나누고 빠르게 전환할 수 있는 인터페이스를 제공합니다. 아래 템플릿을 기준으로 기본 사용법, 변형, 사이즈, 접근성 가이드까지 일관되게 확인할 수 있습니다.

Basic Usage

Default Tabs

기본 탭은 수평 방향으로 콘텐츠를 구분하며, data-tabs 속성을 통해 자동으로 초기화됩니다.

Overview

제품의 핵심 정보를 빠르게 확인할 수 있는 개요 탭입니다.

Specifications

상세 스펙과 기술 정보를 구조화하여 제공합니다.

Reviews

사용자 리뷰와 평점을 모아 보여주는 섹션입니다.

JavaScript Example 
document.addEventListener('DOMContentLoaded', () => {
    BRICKS.Tabs.init();

    const productTabs = document.querySelector('.tabs');
    productTabs.addEventListener('tabChange', (event) => {
        console.log('탭 변경:', event.detail.tab);
    });
});

States

Interactive States

각 상태별 시각 피드백을 확인하여 접근성과 사용성을 검증하세요.

Default

비활성화 전 기본 탭은 중립 색상을 사용합니다.

Hover

호버 시 텍스트 대비가 높아져 선택 가능성을 강조합니다.

Active

현재 탭은 브랜드 컬러로 표시되어 위치를 명확히 합니다.

Focus

키보드 포커스 시 명확한 윤곽선이 나타납니다.

Disabled

사용 불가 상태는 낮은 불투명도와 커서 제어로 표현합니다.

Accessibility

ARIA Attributes

스크린 리더와의 호환을 위해 핵심 ARIA 속성이 자동으로 연결됩니다.

  • role="tablist" – 탭 네비게이션 컨테이너.
  • role="tab" – 각 탭 버튼을 버튼 대신 탭으로 선언.
  • role="tabpanel" – 탭 콘텐츠를 패널로 명시.
  • aria-controls / aria-labelledby – 탭과 패널 간 연결.
  • aria-selected – 현재 활성 탭을 표현.
  • aria-hidden – 비활성 패널을 화면 판독기에서 제외.
  • aria-disabled – 비활성 탭 버튼을 알림.

Keyboard Support

Key Description
Tab 포커스를 탭 그룹으로 이동합니다.
Shift + Tab 이전 포커스 가능한 요소로 이동합니다.
ArrowLeft / ArrowUp 이전 활성 탭으로 순환 이동합니다.
ArrowRight / ArrowDown 다음 활성 탭으로 순환 이동합니다.
Home 첫 번째 사용 가능한 탭으로 이동합니다.
End 마지막 사용 가능한 탭으로 이동합니다.
Enter / Space 포커스된 탭을 활성화합니다.

Focus Management

  • 활성 탭만 tabindex="0" 값을 가지며, 나머지는 -1로 설정됩니다.
  • 탭 클릭 시 포커스가 패널로 이동하지 않으므로 키보드 탐색 흐름이 유지됩니다.
  • 모든 패널은 tabindex="0"으로 설정되어 내부 콘텐츠로 바로 이동할 수 있습니다.
  • 인디케이터는 화면 판독기에 노출되지 않으며 시각적 피드백만 제공합니다.
접근성 이벤트 핸들링 
const settingsTabs = document.querySelector('#settings-tabs');
settingsTabs?.addEventListener('tabChange', (event) => {
    const { button, panel } = event.detail;
    button.focus();
    panel.setAttribute('aria-hidden', 'false');
});

Usage Guidelines

Do's and Don'ts

✅ Do

  • 탭 네비게이션이 3~7개 사이일 때 사용해 인지 부하를 줄입니다.
  • 각 탭 콘텐츠는 문장보다 섹션 단위로 구성해 맥락을 유지하세요.
  • aria 속성과 키보드 패턴이 자동 적용되는 기본 마크업을 유지합니다.
  • 반응형 환경에서 탭이 여러 줄로 래핑되지 않도록 라벨 길이를 검토합니다.

❌ Don't

  • 상태 필터처럼 실시간 데이터가 많은 경우 탭 대신 드롭다운을 고려합니다.
  • 탭 콘텐츠 간 논리적 연관성이 없는 항목을 한 그룹에 배치하지 않습니다.
  • 탭 버튼을 링크로 대체하거나 role 속성을 제거하지 않습니다.
  • 새로운 변형을 추가할 때 템플릿 구조를 벗어난 HTML을 작성하지 않습니다.
