Shadow System

BRICK 디자인 시스템의 깊이와 계층을 표현하는 그림자 체계

Shadow Scale

미니멀한 Black & White 시스템에 최적화된 6단계 그림자 스케일

--ds-shadow-xs 0 1px 2px 0 rgba(0, 0, 0, 0.05) 미묘한 구분
--ds-shadow-sm 0 2px 4px 0 rgba(0, 0, 0, 0.06) 기본 버튼
--ds-shadow-md 0 4px 8px 0 rgba(0, 0, 0, 0.08) 카드 기본
--ds-shadow-lg 0 8px 16px 0 rgba(0, 0, 0, 0.10) 드롭다운
--ds-shadow-xl 0 16px 32px 0 rgba(0, 0, 0, 0.12) 모달
--ds-shadow-2xl 0 24px 48px 0 rgba(0, 0, 0, 0.14) 팝오버

Usage Guidelines

Elevation Hierarchy

  • Level 0: 배경과 같은 높이 (그림자 없음)
  • Level 1-2: 콘텐츠 카드, 기본 버튼
  • Level 3-4: 떠있는 요소 (드롭다운, 모달)
  • Level 5: 최상위 레이어 (알림, 툴팁)

Best Practices

  • 일관성: 같은 레벨의 요소는 같은 그림자 사용
  • 상호작용: 호버/클릭 시 그림자 변화로 피드백 제공
  • 성능: 과도한 그림자는 성능에 영향을 줄 수 있음
  • 접근성: 그림자만으로 구분하지 말고 border도 함께 사용

CSS Implementation

/* Basic shadow application */
.card {
    background: var(--ds-white);
    box-shadow: var(--ds-shadow-md);
    border-radius: var(--ds-radius-lg);
}

/* Hover effect */
.card:hover {
    box-shadow: var(--ds-shadow-lg);
    transform: translateY(-2px);
    transition: all var(--ds-duration-200);
}

/* Active/pressed state */
.button:active {
    box-shadow: var(--ds-shadow-xs);
    transform: translateY(1px);
}

/* Dark mode adjustment */
[data-theme="dark"] .card {
    box-shadow: var(--ds-shadow-xl);
    border: 1px solid var(--ds-gray-200);
}
