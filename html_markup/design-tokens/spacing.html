Usage Guidelines

Spacing Scale Usage

  • space-1 ~ space-2: 아이콘과 텍스트 사이, 작은 요소 간격
  • space-3 ~ space-4: 버튼 내부 패딩, 폼 요소 간격
  • space-6 ~ space-8: 카드 내부 패딩, 섹션 간격
  • space-12 ~ space-16: 큰 섹션 사이, 페이지 패딩
  • space-20 ~ space-24: 페이지 레벨 간격

Border Radius Usage

  • radius-sm: 작은 버튼, 인풋 필드
  • radius-base ~ radius-md: 일반 버튼, 카드
  • radius-lg ~ radius-xl: 모달, 큰 카드
  • radius-2xl ~ radius-3xl: 특별한 디자인 요소
  • radius-full: 원형 버튼, 아바타

CSS Variables Example

/* Component spacing */
.my-component {
    padding: var(--ds-space-4);
    margin-bottom: var(--ds-space-6);
    gap: var(--ds-space-2);
    border-radius: var(--ds-radius-lg);
}

/* Container sizing */
.container {
    max-width: var(--ds-container-5xl);
    margin: 0 auto;
    padding: var(--ds-space-8);
}

/* Z-index layering */
.modal {
    z-index: var(--ds-z-modal);
}

/* Transitions */
.button {
    transition: var(--ds-transition-colors);
    transition-duration: var(--ds-duration-200);
}
