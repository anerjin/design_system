Badge

Accessibility

ARIA Attributes

Badge 컴포넌트는 다음과 같은 접근성 기능을 구현합니다:

  • aria-label - 스크린 리더를 위한 레이블 제공
  • role="status" - 상태 정보임을 명시
  • aria-live="polite" - 동적 업데이트 알림

Color Contrast

모든 배지 색상은 WCAG AA 기준(4.5:1)을 충족합니다.

Usage Guidelines

Do's and Don'ts

✅ Do

  • 짧고 명확한 텍스트 사용 (1-3글자 권장)
  • 컨텍스트에 맞는 색상 선택
  • 일관된 크기와 스타일 사용
  • 접근성을 위한 ARIA 레이블 제공
  • 큰 숫자는 "99+"와 같이 축약

❌ Don't

  • 너무 긴 텍스트 사용 금지
  • 한 화면에 너무 많은 배지 사용 금지
  • 의미 없는 색상 조합 사용 금지
  • 중요한 정보를 배지만으로 전달 금지
  • 애니메이션 과다 사용 금지
