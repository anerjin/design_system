Accessibility

ARIA Attributes

버튼 컴포넌트는 다음과 같은 접근성 기능을 지원합니다:

  • role="button" - 버튼 역할 명시 (필요시)
  • aria-pressed - 토글 버튼의 상태 표시
  • aria-disabled - 비활성화 상태 표시
  • aria-label - 아이콘 전용 버튼에 레이블 제공
  • aria-busy - 로딩 상태 표시

Keyboard Support

Key Description
Tab 버튼으로 포커스 이동
Enter 버튼 활성화
Space 버튼 활성화 (form 버튼이 아닌 경우)

Focus Management

  • 모든 버튼은 키보드로 접근 가능합니다
  • 포커스 링이 명확하게 표시됩니다
  • 비활성화된 버튼은 포커스를 받지 않습니다

Usage Guidelines

Do's and Don'ts

✅ Do

  • 명확하고 간결한 버튼 텍스트 사용
  • 중요도에 따른 적절한 버튼 변형 선택
  • 아이콘 전용 버튼에 aria-label 제공
  • 로딩 상태를 명확하게 표시
  • 일관된 크기와 스타일 유지

❌ Don't

  • 한 화면에 너무 많은 Primary 버튼 사용
  • 버튼 텍스트에 불필요한 기호나 이모지 사용
  • 비활성화 이유를 설명하지 않음
  • 너무 작거나 큰 버튼 크기 사용
  • 버튼과 링크를 혼용
