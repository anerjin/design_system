Special Features

Select All Pattern

알림 설정

Select All 체크박스는 자동으로 indeterminate 상태를 관리합니다.

코드 보기 
<fieldset class="checkbox-group" data-required>
  <legend>알림 설정</legend>

  <!-- Select All -->
  <label class="checkbox">
    <input type="checkbox" class="checkbox__input" data-checkbox-select-all>
    <span class="checkbox__box">
      <span class="checkbox__checkmark"></span>
    </span>
    <span class="checkbox__label">모든 알림 받기</span>
  </label>

  <!-- Individual Options -->
  <label class="checkbox">
    <input type="checkbox" class="checkbox__input" name="notifications" value="email">
    <span class="checkbox__box">
      <span class="checkbox__checkmark"></span>
    </span>
    <span class="checkbox__label">이메일 알림</span>
  </label>

  <!-- More options... -->
</fieldset>

Accessibility

ARIA Attributes

체크박스 컴포넌트는 다음과 같은 접근성 기능을 제공합니다:

  • Native 시맨틱 - <input type="checkbox">는 이미 체크박스 역할을 가짐
  • aria-checked="mixed" - Indeterminate 상태에서만 사용
  • 암묵적 라벨 연결 - <label>로 감싸진 구조로 자동 연결
  • aria-describedby - 추가 설명 텍스트 연결 (필요시)
  • aria-required - 필수 선택 그룹 표시
  • aria-invalid - 유효성 검사 상태 표시

Indeterminate State

체크박스는 세 가지 상태를 지원합니다:

  • Unchecked - 빈 박스 표시 (기본값)
  • Checked - 체크 마크(✓) 표시
  • Indeterminate - 작은 사각형(■) 표시 (부분 선택)

사용 케이스: Indeterminate 상태는 주로 Select All 체크박스에서 하위 항목이 부분적으로만 선택되었을 때 사용됩니다.

Usage Guidelines

Do's and Don'ts

✅ Do

  • Native HTML 요소 우선 사용
  • 모든 체크박스에 명확한 레이블 제공
  • 관련 옵션은 fieldset으로 그룹화
  • Select All 패턴에 indeterminate 상태 활용
  • 키보드 접근성 보장 (Tab, Space)
  • 충분한 터치 영역 확보 (최소 44x44px)
  • 선택 가능한 항목 수 제한 (7±2 규칙)

❌ Don't

  • 중복 ARIA 속성 사용
  • 레이블 없는 체크박스 배치
  • 색상만으로 상태 표시
  • 너무 작은 클릭 영역 설정
  • 체크박스를 라디오 버튼처럼 사용
  • 중요한 설정을 기본 체크 상태로
  • 긴 레이블 텍스트 사용
