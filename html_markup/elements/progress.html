Progress

프로그레스는 작업 진행 상태를 시각적으로 표시하는 컴포넌트입니다. 선형 바, 원형, 다단계 등 다양한 형태를 지원합니다.

Accessibility

ARIA Attributes

Progress 컴포넌트는 다음과 같은 접근성 기능을 구현합니다:

  • role="progressbar" - 진행 표시기 역할 명시
  • aria-valuenow - 현재 진행 값
  • aria-valuemin - 최소값 (일반적으로 0)
  • aria-valuemax - 최대값 (일반적으로 100)
  • aria-label - 진행 표시기 설명

Best Practices

  • 진행 상황에 대한 텍스트 설명 제공
  • 색상만으로 정보를 전달하지 않기
  • 동적 업데이트 시 aria-live 영역 활용
  • 키보드 사용자를 위한 대체 정보 제공

Usage Guidelines

Do's and Don'ts

✅ Do

  • 진행률과 함께 텍스트 레이블 제공
  • 작업이 완료되면 성공 상태 표시
  • 긴 작업의 경우 indeterminate 사용
  • 적절한 색상으로 상태 구분
  • 반응형 크기 고려

❌ Don't

  • 너무 많은 진행 표시기 동시 사용 금지
  • 의미 없는 애니메이션 과다 사용 금지
  • 색상만으로 상태 전달 금지
  • 너무 빠른 업데이트 주기 금지
  • 불명확한 진행 상태 표시 금지
