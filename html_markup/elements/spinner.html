Spinner

.spinner--{type} Animation type dots, pulse, bars

Accessibility

ARIA Attributes

Spinner 컴포넌트는 다음과 같은 접근성 기능을 구현합니다:

  • role="status" - 상태 표시기 역할 명시
  • aria-live="polite" - 화면 리더에 상태 변경 알림
  • aria-label="Loading" - 로딩 상태 설명
  • aria-busy="true" - 컨테이너가 업데이트 중임을 표시

Best Practices

  • 스피너와 함께 텍스트 설명 제공
  • 장시간 로딩 시 진행 상황 정보 제공
  • 포커스 관리 고려 (로딩 완료 후)
  • 적절한 타임아웃 설정

Usage Guidelines

Do's and Don'ts

✅ Do

  • 로딩 상태에 대한 명확한 설명 제공
  • 적절한 크기의 스피너 사용
  • 컨텍스트에 맞는 색상 선택
  • 긴 작업의 경우 진행률 표시 고려
  • 로딩 완료 후 포커스 관리

❌ Don't

  • 너무 많은 스피너 동시 표시 금지
  • 불필요한 애니메이션 과다 사용 금지
  • 너무 작거나 큰 크기 사용 금지
  • 명확한 피드백 없이 무한 로딩 금지
  • 대비가 낮은 색상 사용 금지
