Accessibility

Keyboard Navigation

키 동작 설명
Space 토글 전환 스위치를 켜거나 끕니다
Enter 토글 전환 스위치를 켜거나 끕니다
ArrowRight 켜기 스위치가 꺼져있을 때 켭니다
ArrowLeft 끄기 스위치가 켜져있을 때 끕니다
Tab 포커스 이동 다음 요소로 포커스를 이동합니다
Shift + Tab 포커스 역방향 이동 이전 요소로 포커스를 이동합니다

ARIA Attributes

속성 값 설명
role="switch" switch 요소가 토글 스위치임을 나타냅니다
aria-checked true / false 스위치의 현재 상태를 표시합니다
aria-disabled true / false 스위치의 비활성화 상태를 표시합니다
aria-label 문자열 스위치의 목적을 설명하는 레이블
aria-labelledby ID 참조 연결된 레이블 요소의 ID

Implementation Example

코드 보기 
<!-- 접근성을 준수하는 토글 스위치 -->
<button class="toggle"
        role="switch"
        aria-checked="false"
        aria-label="알림 설정">
    <span class="toggle__track">
        <span class="toggle__thumb"></span>
    </span>
</button>

<!-- 레이블과 함께 사용하는 경우 -->
<div class="toggle-wrapper">
    <button class="toggle"
            id="notifications-toggle"
            role="switch"
            aria-checked="false">
        <span class="toggle__track">
            <span class="toggle__thumb"></span>
        </span>
    </button>
    <label for="notifications-toggle" class="toggle__label">
        알림 받기
    </label>
</div>

<!-- JavaScript 이벤트 리스너 -->
<script>
// toggleChange 커스텀 이벤트 사용
document.querySelector('.toggle').addEventListener('toggleChange', function(e) {
    console.log('Toggle state:', e.detail.checked);
});
</script>
