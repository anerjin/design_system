Configuration

Customize DOI INC to perfectly match your brand identity. Every aspect of the design system can be configured through CSS variables.

🎨 Complete Control

DOI INC uses CSS custom properties (variables) for all design tokens, making it easy to customize colors, typography, spacing, and more without modifying the source code.

Quick Customization

Create a custom theme in minutes by overriding CSS variables:

/* custom-theme.css */
:root {
  /* Brand Colors */
  --ds-brand-primary: #5b21b6;    /* Your primary brand color */
  --ds-brand-secondary: #ec4899;   /* Your secondary brand color */

  /* Typography */
  --ds-font-sans: 'Inter', system-ui, sans-serif;
  --ds-font-mono: 'JetBrains Mono', monospace;

  /* Spacing & Sizing */
  --ds-radius-base: 12px;          /* Border radius */
  --ds-spacing-unit: 4px;          /* Base spacing unit */
}

Manual Dark Mode Toggle

Control dark mode with JavaScript:

// Simple toggle
function toggleDarkMode() {
  document.documentElement.setAttribute(
    'data-theme',
    document.documentElement.getAttribute('data-theme') === 'dark'
      ? 'light'
      : 'dark'
  );
}
// Toggle with localStorage persistence
function toggleDarkMode() {
  const currentTheme = document.documentElement.getAttribute('data-theme');
  const newTheme = currentTheme === 'dark' ? 'light' : 'dark';

  document.documentElement.setAttribute('data-theme', newTheme);
  localStorage.setItem('theme', newTheme);
}

// Load saved preference on page load
document.addEventListener('DOMContentLoaded', () => {
  const savedTheme = localStorage.getItem('theme') || 'light';
  document.documentElement.setAttribute('data-theme', savedTheme);
});
// Respect system preference with manual override
function initTheme() {
  const savedTheme = localStorage.getItem('theme');

  if (savedTheme) {
    // User has manually selected a theme
    document.documentElement.setAttribute('data-theme', savedTheme);
  } else {
    // Use system preference
    const prefersDark = window.matchMedia('(prefers-color-scheme: dark)').matches;
    document.documentElement.setAttribute('data-theme', prefersDark ? 'dark' : 'light');
  }
}

// Listen for system preference changes
window.matchMedia('(prefers-color-scheme: dark)').addEventListener('change', (e) => {
  if (!localStorage.getItem('theme')) {
    document.documentElement.setAttribute('data-theme', e.matches ? 'dark' : 'light');
  }
});

/* custom-bricks-theme.css */

/* 1. Import base DOI INC styles */
@import '@bricks/design-system/dist/bricks.css';

  /* === Brand Identity === */
  --ds-brand-primary: #6366f1;      /* Indigo */
  --ds-brand-secondary: #ec4899;     /* Pink */

  /* === Typography === */
  --ds-font-sans: 'Inter', system-ui, sans-serif;
  --ds-font-heading: 'Poppins', var(--ds-font-sans);

  /* === Spacing === */
  --ds-spacing-unit: 4px;

  /* === Components === */
  --ds-radius-base: 12px;
  --btn-height-base: 44px;
  --input-height: 44px;

  /* === Shadows === */
  --ds-shadow-sm: 0 2px 8px rgb(0 0 0 / 0.08);
  --ds-shadow-md: 0 4px 16px rgb(0 0 0 / 0.12);

  /* === Transitions === */
  --ds-duration-base: 200ms;
}

/* 3. Dark mode overrides */
[data-theme="dark"] {
  --ds-bg-primary: #0f0f0f;
  --ds-bg-secondary: #1a1a1a;
  --ds-text-primary: #f5f5f5;
  --ds-border: #2a2a2a;
}

/* 4. Component-specific customizations */
.btn--primary {
  background: linear-gradient(135deg,
    var(--ds-brand-primary) 0%,
    var(--ds-brand-secondary) 100%);
}

/* 5. Responsive adjustments */
@media (max-width: 768px) {
  :root {
    --ds-text-base: 15px;
    --btn-height-base: 40px;
  }
}

Best Practices

✅

Do

  • Use CSS variables for all customizations
  • Create a separate theme file for your overrides
  • Test your theme in both light and dark modes
  • Use semantic color names for maintainability
  • Document your custom variables
❌

Don't

  • Modify the core DOI INC files directly
  • Use hard-coded colors in your components
  • Override styles with !important
  • Break the spacing system consistency
  • Ignore accessibility when customizing
