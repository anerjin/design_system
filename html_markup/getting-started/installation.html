Installation

Get started with DOI INC in minutes. Choose your preferred installation method and start building beautiful interfaces.

📋 Prerequisites

Before you begin, make sure you have Node.js version 16.0 or higher installed on your system.

Quick Setup

Choose your preferred method to get started with DOI INC Design System:

Recommended

Package Manager

Best for modern JavaScript projects with build tools

# Using npm
npm install @bricks/design-system

# Using yarn
yarn add @bricks/design-system

# Using pnpm
pnpm add @bricks/design-system

CDN

Quick setup without any build tools

<!-- Add to your HTML head -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@bricks/design-system@latest/dist/bricks.min.css">

<!-- Optional: Include Pretendard font -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/orioncactus/pretendard/dist/web/static/pretendard.min.css">

Direct Download

Download and host the files yourself

Download Latest (v1.0.0) View on GitHub

Basic Setup

1. Import CSS

After installation, import DOI INC CSS into your project:

/* In your main CSS file */
@import '@bricks/design-system/dist/bricks.css';

/* Or import individual modules */
@import '@bricks/design-system/dist/tokens.css';
@import '@bricks/design-system/dist/components.css';
@import '@bricks/design-system/dist/utilities.css';
// In your main SCSS file
@import '@bricks/design-system/dist/bricks';

// Or import individual modules
@import '@bricks/design-system/dist/tokens';
@import '@bricks/design-system/dist/components';
@import '@bricks/design-system/dist/utilities';
// In your JavaScript entry point
import '@bricks/design-system/dist/bricks.css';

// Or import individual modules
import '@bricks/design-system/dist/tokens.css';
import '@bricks/design-system/dist/components.css';
import '@bricks/design-system/dist/utilities.css';

2. Add HTML Structure

Start with our basic HTML template:

<!DOCTYPE html>
<html lang="en" data-theme="light">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>My App with DOI INC</title>

    <!-- DOI INC CSS -->
    <link rel="stylesheet" href="path/to/bricks.css">

    <!-- Box Icons (optional) -->
    <script defer src="../assets/js/lucide-icons.js"></script>
</head>
<body>
    <div class="container">
        <h1>Welcome to DOI INC</h1>
        <button class="btn btn--primary">Get Started</button>
    </div>
</body>
</html>

Version Management

ℹ️ Semantic Versioning

DOI INC follows semantic versioning (SemVer). We recommend using a specific version in production to avoid unexpected breaking changes.

Specify Version

// package.json
{
  "dependencies": {
    "@bricks/design-system": "^1.0.0"  // Allow patch and minor updates
    // or
    "@bricks/design-system": "~1.0.0"  // Allow only patch updates
    // or
    "@bricks/design-system": "1.0.0"   // Exact version
  }
}

CDN with Version

<!-- Specific version -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@bricks/design-system@1.0.0/dist/bricks.min.css">

<!-- Latest version (use with caution in production) -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@bricks/design-system@latest/dist/bricks.min.css">

Troubleshooting

Styles are not applying correctly

Make sure DOI INC CSS is loaded before your custom styles. Check the browser DevTools to ensure the CSS file is loaded without errors.

Icons are not showing

DOI INC uses Box Icons. Make sure to include the Box Icons CSS:

<script defer src="../assets/js/lucide-icons.js"></script>
Dark mode is not working

Ensure the data-theme attribute is set on the HTML element:

// Toggle dark mode
document.documentElement.setAttribute('data-theme', 'dark');
