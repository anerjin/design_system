Quick Start

Get up and running with DOI INC in less than 5 minutes. Choose your preferred installation method and start building.

Install via NPM

npm install @bricks/design-system

# or with yarn
yarn add @bricks/design-system

# or with pnpm
pnpm add @bricks/design-system

Then import in your main CSS file:

@import '@bricks/design-system/dist/bricks.min.css';

Use via CDN

Add this to your HTML head:

<!-- DOI INC CSS -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@bricks/design-system/dist/bricks.min.css">

<!-- Optional: Pretendard Font -->
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/orioncactus/pretendard/dist/web/static/pretendard.min.css">
