Accessibility

ARIA Attributes

This component implements the following accessibility features:

  • aria-label - Provides accessible name
  • role - Defines semantic role
  • aria-current - Indicates current state
  • aria-disabled - Indicates disabled state

Keyboard Support

Key Description
Tab Navigate between focusable elements
Enter Activate the focused element
Space Activate buttons and checkboxes
Esc Close or cancel the current operation

API Reference

Properties & Classes

Class/Property Description Values
.component Base component class Required
.component--{size} Size modifier sm, lg
.component--{variant} Style variant primary, secondary
data-component JavaScript initialization Required for JS

JavaScript Methods

Method Parameters Description
init() - Initialize all components
destroy() element Remove component instance
update() options Update component options

Events

Event Description Event Data
component:init Fired when component initializes { element }
component:change Fired when state changes { oldValue, newValue }
component:destroy Fired when component is destroyed { element }

Usage Guidelines

Do's and Don'ts

✅ Do

  • Use semantic HTML elements
  • Provide appropriate ARIA labels
  • Ensure keyboard accessibility
  • Test with screen readers

❌ Don't

  • Rely solely on color to convey information
  • Remove focus indicators
  • Use placeholder text as labels
  • Forget to test on mobile devices
