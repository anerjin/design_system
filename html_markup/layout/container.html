Container Layout

컨테이너는 콘텐츠 폭을 제한하고 중앙에 정렬하는 레이아웃의 기본 단위입니다. 아래 예제는 템플릿 구조에 맞춰 기본 사용법과 변형, 실전 패턴을 정리한 것입니다.

Basic Usage

Default Container

`.container`는 최대 1200px 너비를 갖고, 뷰포트에 따라 좌우 여백을 자동으로 조정합니다.

기본 컨테이너는 데스크톱에서 1200px까지 확장되고, 더 작은 화면에서는 좌우 여백을 유지한 채 100% 폭을 차지합니다.
HTML 코드 보기 
<div class="container">
    <p>Centered content with max-width</p>
</div>

Size Variations

Preset Widths

다양한 화면 밀도를 지원하기 위해 다섯 가지 고정 폭 프리셋과 유동형 컨테이너를 제공합니다.

`.container--sm` · 640px
`.container--md` · 768px
`.container` · 1200px
`.container--lg` · 1440px
`.container--xl` · 1920px
`.container--fluid` · width: 100%
.container--sm .container--md .container--lg .container--xl .container--fluid

Padding Options

컨테이너 내부 여백은 페이지 특성에 따라 유연하게 선택합니다.

`.container--no-padding` · padding: 0
`.container--padding-sm` · padding: 16px
`.container--padding-md` · padding: 24px
`.container--padding-lg` · padding: 32px
`.container--padding-xl` · padding: 48px

Layout Patterns

Centered Content

`container--center`는 뷰포트 내에서 콘텐츠를 수직·수평 중앙에 배치합니다.

대화나 빈 상태 화면처럼 중앙 정렬이 필요한 경우 사용합니다.
HTML 코드 보기 
<div class="container container--center">
    <div class="empty-state">Centered box</div>
</div>

Responsive Breakpoints

`.container--responsive`는 Tailwind 스타일 브레이크포인트에 맞춰 점진적으로 최대 너비를 확장합니다.

모바일에서는 패딩만 유지되고, sm = 640px, md = 768px, lg = 1024px, xl = 1280px, 2xl = 1536px으로 차례대로 확장됩니다.

Sidebar Layout

`.container-with-sidebar`는 고정 폭 사이드바와 가변 본문을 구성하는 헬퍼입니다.

메인 콘텐츠 (flex:1)
사이드바 (300px)
좌측 고정 사이드바 패턴
비주얼 또는 필터
.container-with-sidebar .container-with-sidebar--left

Reference

Class Mapping

Class Description Max Width / Padding
.container 기본 중앙 정렬 컨테이너 1200px
.container--sm / .container--md / .container--lg / .container--xl 브레이크포인트별 고정 폭 640 / 768 / 1440 / 1920px
.container--fluid 전체 폭 사용 100%
.container--responsive 뷰포트에 따라 점진적 확장 640 → 1536px
.container--padding-{size} 내부 패딩 조정 (sm, md, lg, xl) 16 · 24 · 32 · 48px
.container--center 수직·수평 중앙 정렬 -
.container-with-sidebar 고정 폭 사이드바 + 가변 본문 aside 300px

Usage Guidelines

Do's and Don'ts

✅ Do

  • 페이지 유형에 맞춰 적절한 최대 너비(콘텐츠 가독성)를 선택합니다.
  • 반응형 레이아웃에서는 .container--responsive와 사이즈 프리셋을 혼합해 사용합니다.
  • 내부 패딩 클래스로 헤더·본문·푸터 등 레이아웃 간 간격을 통일합니다.
  • 사이드바 레이아웃에는 가변 컨텐츠 영역이 충분히 남도록 최소 폭을 검토합니다.

❌ Don't

  • 컨테이너 안에 또 다른 고정 폭 컨테이너를 중첩해 과도한 여백을 만들지 않습니다.
  • 본문 텍스트가 너무 긴 경우 .container--fluid만으로 레이아웃을 구성하지 않습니다.
  • 임베드나 미디어가 있을 때는 패딩이 제거된 상태에서 경계가 맞는지 확인하지 않고 배포하지 않습니다.
  • 사이드바 레이아웃을 모바일에 그대로 적용해 좌우 스크롤을 강제하지 않습니다.
