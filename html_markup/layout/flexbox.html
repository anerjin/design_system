Flexbox Utilities

Flexbox 유틸리티는 정렬과 공간 분배를 빠르게 구성하도록 도와줍니다. 템플릿 구조에 맞춰 방향, 정렬, 랩핑, 간격 패턴을 예제로 정리했습니다.

Reference

Utility Summary

Class Description Notes
.flex / .flex--inline 컨테이너를 flex 또는 inline-flex로 전환 -
.flex--row, .flex--column, .flex--row-reverse, .flex--column-reverse 플렉스 방향 설정 반응형 접두사 사용 가능
.flex--wrap, .flex--nowrap, .flex--wrap-reverse 랩핑 전략 조정 컨테이너 폭이 제한된 카드 레이아웃에서 활용
.flex--justify-* 주 축 정렬 (start / center / end / between / around / evenly) 네비게이션, 버튼 그룹 정렬
.flex--align-* 교차 축 정렬 (start / center / end / stretch / baseline) 높이가 다른 요소 정렬
.flex--gap-{token} 아이템 간 간격 설정 0, sm, md, lg, xl, 2xl 토큰 제공
.flex--md-row 등 반응형 변형 프리픽스 (sm/md/lg/xl) 컬럼 → 로우 전환 등 구성

Usage Guidelines

Do's and Don'ts

✅ Do

  • 간단한 1차 정렬에는 Flexbox, 복잡한 다차원 정렬에는 Grid를 선택합니다.
  • 레이아웃 전환 시 반응형 접두사를 활용해 모바일 퍼스트 전략을 유지합니다.
  • 간격 조절은 `flex--gap-*` 토큰을 사용해 디자인 시스템 간격 스케일을 공유합니다.
  • 정렬이 필요한 요소는 가능한 한 동일한 높이 또는 패딩을 맞춰 시각적 안정감을 유지합니다.

❌ Don't

  • 플렉스 아이템에 임의의 마진을 섞어 gap과 혼용하지 않습니다.
  • 주 축 방향과 맞지 않는 정렬 클래스를 중복 선언하지 않습니다.
  • 복잡한 카드 레이아웃에서 wrap 사용 시 요소 폭이 깨지지 않는지 확인하지 않고 배포하지 않습니다.
  • 고정 높이 요소를 baseline 정렬에 사용해 예상치 못한 기준선을 만들지 않습니다.
