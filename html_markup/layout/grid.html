Utility Summary

Class Description Notes
.grid 그리드 컨테이너 활성화 12 컬럼 시스템 기반
.grid__col--{n} n/12 만큼의 폭 사용 1 ≤ n ≤ 12
.grid__col--{bp}-{n} 브레이크포인트별 재정의 bp = sm / md / lg / xl
.grid--gap-{token} 컬럼·로우 간격 설정 0, sm, md, lg, xl 지원
.grid--justify-* 수평 정렬(start/center/end/between) 주로 카드 나열에서 사용
.grid--align-* 수직 정렬(start/center/end/stretch) 높이가 다른 카드 정렬

Usage Guidelines

Do's and Don'ts

✅ Do

  • 레이아웃을 설계할 때 모바일 우선으로 100% 폭에서 시작합니다.
  • 브레이크포인트 재정의를 최소화해 유지보수를 쉽게 유지합니다.
  • gap 토큰을 사용해 디자인 시스템 간격을 일관되게 적용합니다.
  • 정렬 유틸리티로 홀수 개 카드도 중앙 정렬하여 균형을 맞춥니다.

❌ Don't

  • 그리드 안에서 임의의 마진을 섞어 gap과 충돌하지 않도록 합니다.
  • 불필요하게 많은 브레이크포인트를 선언해 CSS를 복잡하게 만들지 않습니다.
  • 컬럼 합이 12를 초과하지 않았는지 항상 확인합니다.
  • 한 컬럼에 너무 많은 콘텐츠를 넣어 가독성이 흐트러지지 않도록 합니다.
