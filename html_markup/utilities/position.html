Position Utilities

위치 제어 유틸리티는 요소를 문서 흐름과 독립적으로 배치할 때 사용합니다. 기본 타입, 고정/스티키 패턴, z-index 레이어링, float 활용을 예제로 정리했습니다.

Position Types

Static · Relative · Absolute

Static (기본)
Relative (top:16 / left:16)
Absolute (top:12 / right:12)
HTML 코드 보기 
<div class="position-relative">
    <div class="position-static">Static</div>
    <div class="position-relative" style="top:16px; left:16px;">Relative</div>
    <div class="position-absolute" style="top:12px; right:12px;">Absolute</div>
</div>

Fixed

`.position-fixed`는 뷰포트에 고정됩니다.

Usage Guidelines

Do's and Don'ts

✅ Do

  • absolute 요소는 항상 부모를 `position-relative`로 지정해 의도치 않은 위치 계산을 방지합니다.
  • fixed 요소를 사용할 때는 뷰포트 패딩이나 safe area를 고려합니다.
  • sticky 헤더는 충분한 top 값을 주고, z-index로 다른 콘텐츠 위에 배치합니다.
  • z-index는 레이어 범위별로 상수 테이블을 정의해 팀 내 컨벤션을 공유합니다.

❌ Don't

  • 플로트를 최신 레이아웃 대안(flex/grid) 대신 기본 레이아웃 도구로 사용하지 않습니다.
  • position을 남용하여 DOM 순서와 포커스 순서가 어긋나지 않도록 주의합니다.
  • 높이를 갖지 않는 부모에 absolute 요소만 배치해 레이아웃이 무너지는 상황을 만들지 않습니다.
  • 명확한 레이어 전략 없이 z-index를 임의로 증가시키지 않습니다.
