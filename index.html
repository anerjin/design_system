Overview

Get started with BRICKS Design System

BRICKS is a comprehensive design system that provides everything you need to build modern web applications. From basic elements to complete templates, our system is designed with flexibility and accessibility in mind.

What's Included

  • Elements - Typography, buttons, forms, badges, and more
  • Components - Cards, modals, navigation, alerts, and UI components
  • Sections - Pre-built page sections like heroes, features, and CTAs
  • Templates - Complete page templates for common use cases
  • Layouts - Grid system, containers, and utility classes
