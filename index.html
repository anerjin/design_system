Welcome to BRICKS Design System

A modern, accessible design system built with simplicity and flexibility in mind. Create beautiful, consistent user interfaces with our comprehensive collection of components and utilities.

Introduction

BRICKS is a comprehensive design system that provides everything you need to build modern web applications. From basic elements to complete templates, our system is designed with flexibility and accessibility in mind.

Key Features

  • 🎨 Modern, clean design with light and dark themes
  • ♿ WCAG 2.1 AA compliant for accessibility
  • 📱 Fully responsive and mobile-first approach
  • 🚀 Optimized for performance with minimal CSS
  • 🧩 Modular components for easy customization
  • 📖 Comprehensive documentation with examples

Quick Start

Get started with BRICKS in just a few steps:

<button class="btn btn--primary">Primary Button</button>
<button class="btn btn--secondary">Secondary Button</button>
<button class="btn btn--ghost">Ghost Button</button>

Installation

BRICKS can be installed via npm or used directly from a CDN. Choose the method that best fits your project needs.

Using npm

npm install @bricks/design-system

Using CDN

<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/@bricks/design-system/dist/bricks.min.css">

Configuration

Customize BRICKS to match your brand by overriding CSS variables. All design tokens are defined as CSS custom properties for easy theming.

💡 TIP

You can override any design token by defining custom CSS variables in your root selector.

Custom Theme Example

:root {
  --ds-brand-primary: #624bff;
  --ds-brand-secondary: #ff6b6b;
  --ds-font-family: 'Inter', sans-serif;
  --ds-radius-base: 8px;
}
