Tooltip Component

Tooltip은 마우스 오버나 키보드 포커스 시 추가 정보를 제공하는 보조 컴포넌트입니다. 접근성을 고려한 ARIA 속성과 다양한 위치, 테마 지원 방법을 정리했습니다.

Basic Usage

Hover & Focus

기본 Tooltip은 data-tooltip 속성만으로 텍스트를 지정하며, 포커스와 호버 모두에서 노출됩니다.

알림
HTML 코드 보기 
<span class="tooltip">
    <button type="button" class="tooltip__trigger" data-tooltip="추가 정보">
        Hover or focus me
    </button>
</span>

Variations

Placement

data-tooltip-placement 속성으로 Tooltip 위치를 제어할 수 있습니다.

Light Theme & Rich Content

템플릿 콘텐츠나 키보드 단축키 같은 리치 텍스트를 표시할 수 있습니다.

새 메모 ⌘ShiftN

Accessibility

ARIA & Keyboard Support

  • aria-describedby로 트리거와 Tooltip을 연결하여 보조기기가 설명을 읽도록 합니다.
  • role="tooltip"과 aria-hidden 토글로 노출 상태를 관리합니다.
  • Esc 키를 누르면 Tooltip이 닫히고 포커스는 트리거로 복귀합니다.
  • 포커스 가능한 요소에 Tooltip을 제공하여 키보드 사용자도 동일한 정보를 얻을 수 있도록 합니다.

API Reference

Attributes

Attribute Description Values
data-tooltipTooltip 텍스트문자열
data-tooltip-templateHTML 콘텐츠를 포함한 템플릿 참조요소 ID
data-tooltip-placementTooltip 위치top, bottom, left, right
data-tooltip-theme테마 스킨dark (기본), light

Usage Guidelines

Do's and Don'ts

✅ Do

  • 핵심 정보는 본문에 제공하고 Tooltip은 보조 설명에만 사용합니다.
  • 포커스 가능한 요소와 함께 Tooltip을 배치해 키보드 사용자도 접근할 수 있도록 합니다.
  • 모바일에서는 Tooltip 대신 팝오버 또는 인라인 텍스트로 대체를 검토합니다.
  • 시각적 대비를 충분히 확보해 가독성을 높입니다.

❌ Don't

  • 클릭이 필요한 중요한 정보를 Tooltip 내부에만 배치하지 않습니다.
  • 지나치게 긴 텍스트를 Tooltip에 담아 읽기 어려운 경험을 만들지 않습니다.
  • 자동으로 등장하는 Tooltip을 사용해 포커스 이동을 방해하지 않습니다.
  • 마우스 아웃 시 바로 사라지도록 설정해 실수로 내용을 놓치게 만들지 않습니다.
