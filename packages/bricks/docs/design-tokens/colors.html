Usage Guidelines

색상 사용 원칙

  • Core Colors: 주요 인터랙션과 포커스 포인트에 사용
  • Gray Scale: 배경, 보더, 타이포 계층에 활용
  • Semantic Colors: 상태 피드백(성공/경고/정보/위험)
  • Extended Palette: 브랜딩 및 하이라이트 요소

접근성 체크

  • 핵심 텍스트: 최소 대비 4.5:1
  • 대형 텍스트: 최소 대비 3:1
  • 버튼 & 아이콘: 최소 대비 3:1
  • 하이라이트: 상태색과 대비를 유지
