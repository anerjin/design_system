Accessibility

ARIA Attributes

입력 필드 컴포넌트는 다음과 같은 접근성 기능을 지원합니다:

  • aria-label - 보이지 않는 레이블이 필요한 경우
  • aria-describedby - 도움말 텍스트나 오류 메시지 연결
  • aria-invalid - 입력 오류 상태 표시
  • aria-required - 필수 입력 필드 표시
  • aria-disabled - 비활성화 상태 표시

Keyboard Support

Key Description
Tab 다음 입력 필드로 이동
Shift + Tab 이전 입력 필드로 이동
Enter 폼 제출 (단일 라인 입력 필드)

Best Practices

  • 모든 입력 필드에는 연관된 <label> 요소가 있어야 합니다
  • 필수 필드는 required 속성과 함께 시각적 표시를 제공합니다
  • 오류 메시지는 aria-describedby로 입력 필드와 연결합니다
  • placeholder는 레이블을 대체하지 않으며, 보조 정보로만 사용합니다
  • 충분한 색상 대비를 유지합니다 (WCAG 2.1 AA 기준)

Usage Guidelines

Do's and Don'ts

✅ Do

  • 항상 명확한 레이블 제공
  • 적절한 input type 사용 (email, tel, number 등)
  • 필수 필드 명확하게 표시
  • 유용한 placeholder 텍스트 제공
  • 오류 메시지는 구체적이고 도움이 되도록 작성
  • 키보드 탐색 지원 확인
  • 자동 완성 기능 활용

❌ Don't

  • placeholder를 레이블 대신 사용
  • 너무 작은 터치 영역 설정
  • 오류 메시지에 기술적인 용어 사용
  • 불필요한 필수 필드 설정
  • 한 줄에 너무 많은 입력 필드 배치
  • 레이블과 입력 필드를 멀리 배치
  • 색상만으로 상태 표시
