Select Components

드롭다운 선택 컴포넌트로 사용자가 옵션 목록에서 하나 이상의 항목을 선택할 수 있습니다. 접근성과 사용성을 고려하여 설계되었습니다.

Accessibility

ARIA Attributes

선택 컴포넌트는 다음과 같은 접근성 기능을 지원합니다:

  • aria-label - 보이지 않는 레이블이 필요한 경우
  • aria-describedby - 도움말 텍스트나 오류 메시지 연결
  • aria-invalid - 선택 오류 상태 표시
  • aria-required - 필수 선택 필드 표시
  • aria-multiselectable - 다중 선택 가능 여부

Best Practices

  • 모든 select 요소에는 연관된 <label> 요소가 있어야 합니다
  • 필수 필드는 required 속성과 함께 시각적 표시를 제공합니다
  • 관련 옵션은 <optgroup>으로 그룹화합니다
  • 첫 번째 옵션은 명확한 지시문을 제공합니다 (예: "선택하세요...")
  • 충분한 색상 대비를 유지합니다 (WCAG 2.1 AA 기준)

API Reference

Classes & Properties

Class Description Usage
.select Base select class All select elements
.select--{size} Select size xs, sm, lg, xl
.select--success Success state Valid selection
.select--warning Warning state Attention needed
.select--error Error state Invalid selection
.select-group Group wrapper Select with addons
.select-group__prepend Prepend element Before select
.select-group__append Append element After select

Usage Guidelines

Do's and Don'ts

✅ Do

  • 항상 명확한 레이블 제공
  • 첫 번째 옵션으로 명확한 지시문 제공
  • 관련 옵션은 optgroup으로 그룹화
  • 적절한 기본값 설정 (필요한 경우)
  • 옵션 수가 많은 경우 검색 기능 고려
  • 모바일에서 native select 활용
  • 필수 필드 명확하게 표시

❌ Don't

  • 너무 많은 옵션 나열 (7±2 규칙)
  • 불명확하거나 모호한 옵션 텍스트
  • 중요한 선택을 기본값으로 설정
  • 비슷한 옵션을 섞어서 배치
  • 긴 옵션 텍스트 사용
  • select를 navigation으로 사용
  • 다중 선택을 과도하게 사용
