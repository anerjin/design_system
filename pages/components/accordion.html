API Reference

Classes & Properties

Class Description Values
.accordion Base accordion container Required
.accordion__item Individual accordion item Container for header and content
.accordion__item--open Open accordion item Expanded state
.accordion__header Clickable header button Trigger element
.accordion__header--active Active header state Visual feedback
.accordion__content Content container Collapsible area
.accordion__content--open Open content state Visible content
.accordion__body Content body with padding Inner content
.accordion--{size} Size variants sm, lg
.accordion--flush Remove outer borders Borderless style
.accordion--{color} Color variants primary, success, warning, danger
data-accordion JavaScript initialization Required for JS
data-accordion-multiple Allow multiple open true, false
