Alert Components

사용자에게 중요한 정보를 전달하는 알림 컴포넌트입니다. 다양한 상태와 스타일을 제공합니다.

Basic Usage

Default Alert

This is a default alert message for general information.
코드 보기 
<div class="alert">
    This is a default alert message for general information.
</div>

API Reference

Classes & Properties

Alert Classes

Class Description Values
.alert Base alert container Required
.alert--{variant} Color variant primary, secondary, success, warning, danger, info, light, dark
.alert--solid-{variant} Solid background variant primary, secondary, success, warning, danger, info
.alert--{size} Size modifier sm, lg
.alert--dismissible Dismissible alert -
.alert--accent-{side} Accent border left, top

Alert Elements

Class Description Usage
.alert__icon Icon container Optional
.alert__content Content wrapper Required when using icon
.alert__title Alert title Optional
.alert__description Alert description Optional
.alert__list List of items Optional
.alert__actions Action buttons container Optional
.alert__close Close button With dismissible

Accessibility

ARIA Attributes

Alert 컴포넌트는 다음과 같은 접근성 기능을 구현합니다:

  • role="alert" - 중요한 메시지임을 스크린 리더에 알림
  • aria-label="Close" - 닫기 버튼에 대한 설명
  • aria-live="polite" - 동적 알림에 사용
  • aria-atomic="true" - 전체 알림 내용 읽기

Best Practices

  • 색상만으로 정보를 전달하지 않기 (아이콘, 텍스트 병행)
  • 중요도에 따른 적절한 역할 속성 사용
  • 키보드로 닫기 버튼 접근 가능
  • 충분한 색상 대비 유지

Usage Guidelines

Do's and Don'ts

✅ Do

  • 상태에 맞는 적절한 색상 사용
  • 중요한 정보는 제목과 설명 모두 제공
  • 닫을 수 있는 옵션 제공 (dismissible)
  • 액션이 필요한 경우 명확한 버튼 제공
  • 아이콘으로 시각적 단서 강화

❌ Don't

  • 너무 많은 알림 동시 표시 금지
  • 자동으로 사라지는 중요 정보 금지
  • 색상만으로 상태 구분 금지
  • 너무 긴 텍스트 사용 금지
  • 사용자 작업 방해하는 위치 금지
