Properties

Class Description
.breadcrumb Base breadcrumb container
.breadcrumb__item Individual breadcrumb item
.breadcrumb__link Breadcrumb link
.breadcrumb__icon Icon within breadcrumb
.breadcrumb__item--active Active/current page
.breadcrumb--sm Small size
.breadcrumb--lg Large size
.breadcrumb--slash Slash separator (default)
.breadcrumb--arrow Arrow separator
.breadcrumb--chevron Chevron separator
.breadcrumb--dot Dot separator
.breadcrumb--pipe Pipe separator
.breadcrumb--bg With background
.breadcrumb--dark Dark theme
.breadcrumb--truncate Truncate long items
.breadcrumb--responsive Responsive for mobile

Data Attributes

Attribute Description Example
data-breadcrumb Initialize breadcrumb component data-breadcrumb
data-max-items Maximum items to display before collapsing data-max-items="5"
