Properties

Class Description
.card Base card container
.card__header Card header section
.card__body Card body content
.card__footer Card footer section
.card--elevated Card with shadow
.card--bordered Card with border
.card--flat Flat card without effects
.card--radius-none No border radius (sharp corners)
.card--radius-sm Small border radius (4px)
.card--radius-md Medium border radius (8px)
.card--radius-lg Large border radius (12px - default)
.card--radius-xl Extra large border radius (16px)
.card--radius-2xl 2X large border radius (24px)
.card--radius-3xl 3X large border radius (32px)
.card--radius-full Full border radius (9999px)
