API Reference

Classes & Properties

Card Classes

Class Description Values
.card Base card container (white background) Required
.card--gray Gray background variant Gray background
.card--{variant} Card variant elevated, outlined, flat, clickable
.card--radius-{size} Border radius modifier none, sm, md, lg, xl, 2xl, 3xl, full
.card--horizontal Horizontal layout Side-by-side content

Card Elements

Class Description Usage
.card__header Card header section Optional
.card__title Card title text Header content
.card__subtitle Card subtitle text Secondary text
.card__body Card body content Main content
.card__footer Card footer section Optional
.card__footer--{align} Footer alignment left, center, right, between
.card__actions Action buttons container Button group
.card__image Image container Media content
.card__badge Badge positioning Overlay content

Card Group

Class Description Values
.card-group Cards container grid Required
.card-group--cols-{n} Column count 1, 2, 3, 4

Accessibility

Best Practices

  • 카드가 클릭 가능한 경우 적절한 포커스 상태 제공
  • 카드 내 버튼과 링크는 명확한 액션 설명 포함
  • 이미지에는 의미 있는 alt 텍스트 제공
  • 충분한 색상 대비 유지 (WCAG 2.1 기준)
  • 키보드 탐색 지원 확인

ARIA Attributes

  • role="article" - 독립적인 콘텐츠 블록인 경우
  • aria-label - 카드 제목이 없는 경우 설명 제공
  • tabindex="0" - 클릭 가능한 카드의 키보드 접근성

Usage Guidelines

Do's and Don'ts

✅ Do

  • 일관된 카드 크기와 간격 유지
  • 관련 콘텐츠를 논리적으로 그룹화
  • 적절한 여백과 계층 구조 사용
  • 반응형 디자인 고려
  • 액션 버튼은 카드 하단에 배치

❌ Don't

  • 너무 많은 정보를 한 카드에 포함
  • 중첩된 카드 과도하게 사용
  • 불필요한 그림자 효과 남용
  • 카드 내 여백 불균형
  • 모바일에서 가로 스크롤 발생
