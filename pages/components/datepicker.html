Datepicker Component

Datepicker는 날짜 선택을 위한 접근성 친화적 컴포넌트입니다. 키보드 탐색, ARIA 속성, 범위 선택 등 다양한 패턴을 템플릿 구조로 정리했습니다.

Basic Usage

Single Date Selection

기본 Datepicker는 입력 필드와 토글 버튼으로 구성되며, 팝오버는 dialog 역할과 ARIA 속성으로 연결됩니다.

JavaScript 사용 예시 
document.addEventListener('DOMContentLoaded', () => {
    BRICKS.Datepicker.init();

    const bookingPicker = document.querySelector('#datepicker-basic-input');
    bookingPicker?.closest('[data-datepicker]')
        ?.addEventListener('datepicker:change', (event) => {
            console.log('선택된 날짜:', event.detail.value);
        });
});

Accessibility

ARIA & Keyboard Support

주요 ARIA 속성

  • role="dialog" + aria-modal – 팝오버가 대화 상자임을 알립니다.
  • aria-haspopup="dialog", aria-controls – 입력과 팝오버 연결.
  • role="grid" / role="gridcell" – 날짜 셀을 키보드 탐색 가능한 격자로 표현.
  • aria-selected, aria-current="date" – 선택 상태와 오늘 날짜 전달.
  • 라이브 영역 – 선택 변경 시 보조기기가 읽어줄 수 있도록 설정.

Usage Guidelines

Do's and Don'ts

✅ Do

  • 장애 유형에 관계없이 날짜 선택이 가능하도록 키보드 패턴과 라이브 영역을 유지합니다.
  • 모달 형태의 팝오버를 사용할 때는 토글 버튼과의 연결을 명확하게 설정합니다.
  • 범위 선택 시 최소/최대 날짜를 제공해 사용자 의도를 명확하게 안내합니다.
  • 모바일에서는 인라인 캘린더 또는 전체 화면 모달을 고려합니다.

❌ Don't

  • 달력 외부에서만 날짜 정보를 제공해 화면 읽기 사용자에게 정보를 숨기지 않습니다.
  • 오늘 날짜와 선택 상태를 색상만으로 전달하지 않습니다.
  • 입력 필드를 직접 편집 가능하게 두어 포맷 오류를 허용하지 않습니다.
  • 범위 선택 시 시작일보다 작은 값을 자동으로 종료일에 표시하지 않고 사용자에게 확인을 요청합니다.
