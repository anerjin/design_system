Modal Components

BRICKS Design System의 모달 다이얼로그 컴포넌트입니다. 오버레이 형태로 표시되어 사용자와 상호작용하는 다양한 변형과 기능을 지원합니다.

Basic Usage

<div class="modal" id="modal-basic">
    <div class="modal__dialog">
        <div class="modal__header">
            <h3 class="modal__title">Modal Title</h3>
            <button type="button" class="modal__close">×</button>
        </div>
        <div class="modal__body">
            <p>Modal content goes here</p>
        </div>
        <div class="modal__footer">
            <button class="btn btn--ghost">Cancel</button>
            <button class="btn btn--primary">Confirm</button>
        </div>
    </div>
</div>

API Reference

Classes & Properties

Class Description Values
.modal Base modal container Required
.modal--open Show modal (applied via JS) Visibility state
.modal--centered Center modal vertically Position modifier
.modal--static Static backdrop (no close on click) Interaction modifier
.modal--dark Dark theme variant Theme modifier
.modal__dialog Modal dialog container Content wrapper
.modal__dialog--sm Small dialog (400px max-width) Size modifier
.modal__dialog--lg Large dialog (800px max-width) Size modifier
.modal__dialog--xl Extra large dialog (1200px max-width) Size modifier
.modal__dialog--fullscreen Full screen dialog Size modifier
.modal__dialog--scrollable Scrollable body content Overflow modifier
.modal__header Modal header section Optional
.modal__title Modal title text Header content
.modal__close Close button Interactive element
.modal__body Modal body content Main content
.modal__footer Modal footer section Optional
