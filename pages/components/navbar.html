Properties

Class Description
.navbar Base navbar container
.navbar__container Inner container with max-width
.navbar__brand Brand/logo area
.navbar__menu Navigation links container
.navbar__link Navigation link
.navbar__link--active Active navigation link
.navbar__dropdown Dropdown container
.navbar__dropdown-toggle Dropdown toggle button
.navbar__dropdown-menu Dropdown menu container
.navbar__dropdown-item Dropdown menu item
.navbar__search Search container
.navbar__actions Action buttons container
.navbar__toggle Mobile menu toggle button
.navbar--dark Dark theme navbar
.navbar--fixed Fixed position navbar
.navbar--sticky Sticky position navbar
.navbar--mobile-open Mobile menu open state

Data Attributes

Attribute Description Example
