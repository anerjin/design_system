API Reference

Classes & Properties

Class Description Values
.pagination Base pagination container Required
.pagination__list Pagination list container ul element
.pagination__item Individual page item li element
.pagination__link Page link Clickable element
.pagination__link--active Active/current page Visual indicator
.pagination__link--prev Previous page link Navigation
.pagination__link--next Next page link Navigation
.pagination__link--disabled Disabled state Non-clickable
.pagination__ellipsis Ellipsis separator ...
.pagination--{size} Size variants sm, lg
.pagination--rounded Rounded style Circular buttons
.pagination--simple Simple style No borders
.pagination--center Center alignment Centered
.pagination--end End alignment Right aligned
data-pagination JavaScript initialization Required for JS
