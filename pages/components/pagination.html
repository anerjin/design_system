Properties

Class Description
.pagination Base pagination container
.pagination__list Pagination list container
.pagination__item Individual page item
.pagination__link Page link
.pagination__link--active Active page
.pagination__link--prev Previous page link
.pagination__link--next Next page link
.pagination__ellipsis Ellipsis separator
.pagination--sm Small size
.pagination--lg Large size
.pagination--rounded Rounded style
