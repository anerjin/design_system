Table Component

테이블은 구조화된 데이터를 행과 열로 정리합니다. 템플릿 레이아웃을 기반으로 기본 구조와 변형, 접근성 가이드를 제공합니다.

Basic Usage

Responsive Data Table

.table과 .table-responsive를 조합해 가로 스크롤을 지원합니다.

Employee summary

    <table class="table" data-table>

                <th scope="col">Status</th>
            </tr>
        </thead>
        <tbody>...</tbody>
    </table>

Accessibility

ARIA & Semantics

테이블은 기본적으로 의미 있는 HTML 요소를 사용하므로 ARIA 사용을 최소화합니다.

  • <caption>으로 테이블 목적을 서술하거나 aria-label을 제공합니다.
  • <th scope="col|row">를 사용해 헤더와 데이터 셀 관계를 명시합니다.
  • 정렬 가능 헤더에는 aria-sort를 업데이트합니다.
  • 반응형 래퍼 사용 시 키보드 스크롤이 가능하도록 tabindex="0"를 부여할 수 있습니다.

Keyboard Support

Key Description
Tab 테이블 전체가 포커스 가능한 경우, 스크롤 영역을 탐색합니다.

Usage Guidelines

Do's and Don'ts

✅ Do

  • 열 정렬 또는 필터를 제공할 경우 명확한 아이콘과 정렬 상태를 표시합니다.
  • 모바일에서는 중요 열만 우선 노출하고 나머지는 드로어 또는 세부 페이지로 제공합니다.
  • 숫자 데이터는 오른쪽 정렬로 가독성을 높입니다.
  • 행 클릭이 가능한 경우 커서와 호버 스타일을 일관되게 제공합니다.

❌ Don't

  • 스크롤 시 헤더가 사라져 데이터 의미를 잃지 않도록 합니다.
  • 긴 텍스트를 강제로 줄이는 대신 줄바꿈이나 툴팁을 활용합니다.
  • 로딩 중에 빈 상태 메시지를 그대로 노출하지 않습니다.
  • 도표로 표현해야 할 데이터를 테이블로만 제공하지 않습니다.
