Class Description Values

.tabs__content Tab panels container Contains panels
.tabs__panel Tab panel Content area
.tabs__panel--active Active tab panel Visible panel
.tabs--{size} Tab sizes sm, lg
.tabs--vertical Vertical tabs layout Side navigation
.tabs--pills Pill style tabs Rounded tabs
.tabs--justified Justified tabs Full width
.tabs__button-icon Tab with icon Icon + text
