Usage Guidelines

Border Radius 사용 가이드

  • rounded-sm (2px): 체크박스, 라디오 버튼
  • rounded-base (4px): 작은 버튼, 태그
  • rounded-lg (8px): 기본 버튼, 입력 필드
  • rounded-xl (12px): 카드, 패널
  • rounded-2xl (16px): 모달, 대형 컨테이너
  • rounded-full: 아바타, 아이콘 버튼

Border Width 사용 가이드

  • 1px: 기본 테두리, 구분선
  • 2px: 강조된 테두리, 선택된 상태
  • 4px: 특별 강조, 브랜드 요소
  • 8px: 장식적 요소, 특수 디자인

CSS Implementation

/* Basic border application */
.card {
    border: var(--ds-border-width-1) solid var(--ds-border-color-default);
    border-radius: var(--ds-border-radius-lg);
}

/* Focus state */
.button:focus {
    outline: none;
    box-shadow: 0 0 0 var(--ds-border-width-2) var(--ds-black);
}

/* Hover state */
.card:hover {
    border-color: var(--ds-border-color-strong);
}

/* Dark mode adjustment */
[data-theme="dark"] .card {
    border-color: var(--ds-border-color-default);
}
