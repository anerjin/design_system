Usage Guidelines

색상 사용 원칙

  • Core Colors: 주요 UI 요소와 텍스트
  • Gray Scale: 계층 구조와 깊이 표현
  • Semantic Colors: 상태 피드백 (성공, 경고, 위험, 정보)
  • Extended Palette: 특별한 강조나 브랜딩 요소

접근성 고려사항

  • Large Text (18pt+): Minimum 3:1 contrast
  • Normal Text: Minimum 4.5:1 contrast
  • UI Components: Minimum 3:1 contrast
  • WCAG AAA: 7:1 for normal text
