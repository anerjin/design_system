Avatar Components

Properties

Class Description
.avatar Base avatar container
.avatar--xs Extra small size (24px)
.avatar--sm Small size (32px)
.avatar--lg Large size (48px)
.avatar--xl Extra large size (64px)
.avatar--rounded Rounded corners
.avatar--square Square shape
.avatar--initials Text initials avatar
.avatar--status With status indicator
.avatar__status--online Online status (green)
.avatar__status--away Away status (orange)
.avatar__status--busy Busy status (red)
.avatar__status--offline Offline status (gray)
.avatar-group Avatar group container
