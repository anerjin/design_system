Avatar

아바타는 사용자 프로필 이미지나 이니셜을 표시하는 컴포넌트입니다. 다양한 크기, 모양, 상태 표시기를 지원합니다.

API Reference

Classes & Properties

Avatar Classes

Class Description Values
.avatar Base avatar container Required
.avatar--{size} Size modifier xs, sm, lg, xl
.avatar--{shape} Shape modifier rounded, square
.avatar--initials Text-based avatar -
.avatar--{color} Color variant for initials primary, success, warning, danger, info
.avatar--status Enable status indicator -

Avatar Elements

Class Description Parent

Accessibility

ARIA Attributes

Avatar 컴포넌트는 다음과 같은 접근성 기능을 구현합니다:

  • alt - 이미지에 대한 대체 텍스트 필수
  • aria-label - 이니셜 아바타의 전체 이름 제공
  • role="img" - 이니셜 아바타에 이미지 역할 명시
  • aria-hidden="true" - 장식용 상태 표시기

Best Practices

  • 모든 이미지 아바타에 의미 있는 alt 텍스트 제공
  • 이니셜 아바타에는 전체 이름을 aria-label로 제공
  • 상태 표시기는 별도의 텍스트로 상태 정보 제공
  • 그룹의 경우 전체 그룹을 설명하는 레이블 제공

Usage Guidelines

Do's and Don'ts

✅ Do

  • 일관된 크기 사용 (같은 컨텍스트 내)
  • 의미 있는 alt 텍스트 제공
  • 이니셜은 2글자로 제한
  • 적절한 이미지 해상도 사용
  • 상태 표시기는 명확한 색상 사용

❌ Don't

  • 너무 작은 크기에 상태 표시기 사용 금지
  • 저해상도 이미지 사용 금지
  • 3글자 이상 이니셜 사용 금지
  • 그룹에 너무 많은 아바타 표시 금지
  • 중요한 정보를 상태 색상만으로 전달 금지
