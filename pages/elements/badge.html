Accessibility

Guidelines for accessible badge implementation

  • ✅ Use semantic HTML elements (<span> for decorative, <button> for interactive)
  • ✅ Provide sufficient color contrast (WCAG 2.1 AA)
  • ✅ Include aria-label for icon-only badges
  • ✅ Use role="status" for dynamic count badges
  • ✅ Ensure remove buttons have descriptive labels
  • ✅ Consider screen reader announcements for dynamic updates
  • ✅ Don't rely solely on color to convey meaning
