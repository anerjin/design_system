API Reference

Classes & Properties

Class Description Values
.btn Base button class Required
.btn--{variant} Button variant primary, secondary, success, danger, warning, info, light, dark, ghost
.btn--outline-{variant} Outline variant primary, secondary, success, danger
.btn--{size} Button size xs, sm, md, lg, xl
.btn--loading Loading state Shows spinner
.btn--pill Pill shape Fully rounded
.btn--block Full width 100% width
.btn--icon-only Icon only button Square button
disabled Disabled state HTML attribute
