Button

다양한 상황에 적합한 버튼 컴포넌트입니다. 7가지 변형과 4가지 크기를 지원합니다.

Basic Usage

<button class="btn btn--primary">Primary Button</button>

Variants

Sizes

States

Properties

Class Description Values
.btn Base button class Required
.btn--{variant} Button variant primary, secondary, ghost, danger, success, warning, link
.btn--{size} Button size sm, md, lg, xl
.btn--loading Loading state -
disabled Disabled state HTML attribute
