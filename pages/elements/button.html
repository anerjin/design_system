.btn--secondary Secondary button style Secondary actions

Accessibility

Guidelines for accessible button implementation

  • ✅ Use semantic <button> elements for actions
  • ✅ Use <a> elements for navigation with button styling
  • ✅ Provide aria-label for icon-only buttons
  • ✅ Ensure sufficient color contrast (WCAG 2.1 AA)
  • ✅ Maintain focus visibility for keyboard navigation
  • ✅ Use disabled attribute for inactive buttons
  • ✅ Provide loading state feedback for async operations
