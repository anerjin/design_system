Properties

Class Description Usage
.checkbox Base checkbox wrapper All checkboxes
.checkbox--xs Extra small size Compact UI
.checkbox--sm Small size Reduced size
.checkbox--md Medium size (default) Standard forms
.checkbox--lg Large size Prominent UI

Accessibility

  • ✅ Always use <label> elements with checkboxes
  • ✅ Use aria-label when labels aren't visible
  • ✅ Provide aria-describedby for help text
  • ✅ Use aria-checked for custom implementations
  • ✅ Group related checkboxes with <fieldset>
  • ✅ Use role="checkbox" for custom elements
  • ✅ Ensure keyboard navigation (Space to toggle)
  • ✅ Maintain sufficient color contrast
