Accessibility

Guidelines for accessible form inputs

  • ✅ Always associate labels with inputs using for attribute
  • ✅ Use aria-label when visible labels aren't present
  • ✅ Provide aria-describedby for help text and error messages
  • ✅ Use aria-invalid="true" for inputs with errors
  • ✅ Set aria-required="true" for required fields
  • ✅ Ensure keyboard navigation works properly
  • ✅ Maintain sufficient color contrast for all states
  • ✅ Use semantic HTML5 input types
