Accessibility

  • ✅ Always use <label> elements with select inputs
  • ✅ Use aria-label when labels aren't visible
  • ✅ Provide aria-describedby for help text
  • ✅ Use required attribute for mandatory fields
  • ✅ Group related options with <optgroup>
  • ✅ Ensure keyboard navigation works properly
  • ✅ Provide clear default options
