Accessibility

Guidelines for accessible typography

  • ✅ Maintain proper heading hierarchy (h1 → h2 → h3, never skip levels)
  • ✅ Ensure minimum font size of 14px for body text
  • ✅ Use sufficient color contrast (WCAG 2.1 AA minimum 4.5:1)
  • ✅ Keep line length between 45-75 characters for optimal readability
  • ✅ Use relative units (rem, em) for scalable text
  • ✅ Provide adequate line height (minimum 1.5 for body text)
  • ✅ Use semantic HTML elements for text structure
  • ✅ Support user font size preferences (respect browser zoom)
