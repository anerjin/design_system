Configuration

BRICKS 디자인 시스템을 프로젝트에 맞게 커스터마이징하는 방법을 안내합니다.

CSS 변수 커스터마이징

BRICKS는 CSS 변수를 사용하여 쉽게 커스터마이징할 수 있습니다.

색상 변경

:root {
    /* Primary Color */
    --color-primary-50: #f5f3ff;
    --color-primary-100: #ede9fe;
    --color-primary-200: #ddd6fe;
    --color-primary-300: #c4b5fd;
    --color-primary-400: #a78bfa;
    --color-primary-500: #8b5cf6;  /* 기본 Primary */
    --color-primary-600: #7c3aed;
    --color-primary-700: #6d28d9;
    --color-primary-800: #5b21b6;
    --color-primary-900: #4c1d95;
    
    /* Custom Brand Color */
    --color-brand: var(--color-primary-500);
}

타이포그래피 설정

:root {
    /* Font Family */
    --font-sans: 'Pretendard', -apple-system, BlinkMacSystemFont, sans-serif;
    --font-mono: 'Fira Code', monospace;
    
    /* Font Size Scale */
    --text-xs: 0.75rem;    /* 12px */
    --text-sm: 0.875rem;   /* 14px */
    --text-base: 1rem;     /* 16px */
    --text-lg: 1.125rem;   /* 18px */
    --text-xl: 1.25rem;    /* 20px */
    --text-2xl: 1.5rem;    /* 24px */
    --text-3xl: 1.875rem;  /* 30px */
    --text-4xl: 2.25rem;   /* 36px */
}

다크 모드 설정

시스템 설정을 따르거나 수동으로 다크 모드를 활성화할 수 있습니다.

자동 다크 모드

/* 시스템 설정 따르기 */
@media (prefers-color-scheme: dark) {
    :root {
        --color-bg: #0a0a0a;
        --color-text: #fafafa;
        --color-border: #27272a;
    }
}

수동 다크 모드

/* HTML에 dark 클래스 추가 */
.dark {
    --color-bg: #0a0a0a;
    --color-text: #fafafa;
    --color-border: #27272a;
}

/* JavaScript로 토글 */
document.documentElement.classList.toggle('dark');

컴포넌트 설정

버튼 커스터마이징

:root {
    /* Button Settings */
    --btn-height: 40px;
    --btn-padding-x: 20px;
    --btn-border-radius: 8px;
    --btn-font-size: var(--text-sm);
    --btn-font-weight: 500;
    
    /* Button Colors */
    --btn-primary-bg: var(--color-primary-500);
    --btn-primary-hover: var(--color-primary-600);
    --btn-primary-text: white;
}

카드 커스터마이징

:root {
    /* Card Settings */
    --card-bg: white;
    --card-border: 1px solid var(--color-muted-200);
    --card-radius: 12px;
    --card-padding: 24px;
    --card-shadow: 0 1px 3px 0 rgb(0 0 0 / 0.1);
}

반응형 설정

BRICKS의 반응형 브레이크포인트를 커스터마이징할 수 있습니다.

:root {
    /* Breakpoints */
    --screen-xs: 475px;
    --screen-sm: 640px;
    --screen-md: 768px;
    --screen-lg: 1024px;
    --screen-xl: 1280px;
    --screen-2xl: 1536px;
}

/* 사용 예시 */
@media (min-width: 768px) {
    .container {
        max-width: var(--screen-md);
    }
}

설정 파일 예시

프로젝트 루트에 `bricks.config.css` 파일을 생성하여 모든 커스터마이징을 관리할 수 있습니다.

/* bricks.config.css */
@import '@bricks/design-system/css/bricks.css';

:root {
    /* Your Custom Variables */
    --color-primary-500: #your-brand-color;
    --font-sans: 'Your Font', sans-serif;
    --btn-height: 44px;
    /* ... */
}
