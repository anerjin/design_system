Installation

BRICKS 디자인 시스템을 프로젝트에 설치하는 방법을 알아봅니다.

CDN 사용하기

가장 빠르게 시작하는 방법은 CDN을 통해 CSS 파일을 불러오는 것입니다.

<!-- Design System Tokens -->
<link rel="stylesheet" href="https://cdn.bricks.design/tokens/colors.css">
<link rel="stylesheet" href="https://cdn.bricks.design/tokens/typography.css">
<link rel="stylesheet" href="https://cdn.bricks.design/tokens/spacing.css">

<!-- Components -->
<link rel="stylesheet" href="https://cdn.bricks.design/components/all.css">

NPM 패키지

NPM을 통해 패키지를 설치할 수 있습니다.

npm install @bricks/design-system

CSS Import

/* main.css */
@import '@bricks/design-system/tokens/colors.css';
@import '@bricks/design-system/tokens/typography.css';
@import '@bricks/design-system/tokens/spacing.css';
@import '@bricks/design-system/components/all.css';

다운로드

GitHub에서 전체 소스 코드를 다운로드할 수 있습니다.

git clone https://github.com/bricks/design-system.git
