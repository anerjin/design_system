BRICKS Design System

모던하고 일관된 사용자 경험을 제공하는 디자인 시스템입니다.

시작하기

BRICKS는 Shuriken UI의 디자인 철학을 기반으로 만들어진 포괄적인 디자인 시스템입니다. 일관된 사용자 경험과 빠른 개발을 위한 컴포넌트, 디자인 토큰, 유틸리티를 제공합니다.

주요 특징

🎨 디자인 토큰

색상, 타이포그래피, 간격 등 일관된 디자인 시스템

🧩 컴포넌트

재사용 가능한 UI 컴포넌트와 패턴

📱 반응형

모든 디바이스에서 완벽하게 작동

🌗 다크 모드

라이트/다크 테마 지원

디자인 원칙

  1. 일관성: 모든 인터페이스에서 일관된 경험 제공
  2. 접근성: 모든 사용자가 쉽게 사용할 수 있는 디자인
  3. 확장성: 프로젝트 성장에 따라 확장 가능한 시스템
  4. 성능: 빠르고 효율적인 컴포넌트

기술 스택

  • Pure CSS (No Tailwind)
  • CSS Custom Properties
  • BEM Naming Convention
  • SVG Icon System
  • Responsive Grid System
