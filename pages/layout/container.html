Container

콘텐츠를 중앙에 정렬하고 최대 너비를 제한하는 컨테이너 레이아웃입니다.

Basic Container

This is a basic container. It centers the content and has a maximum width. The content will be responsive and adapt to different screen sizes while maintaining proper margins.

<div class="container">
    <p>Content inside container</p>
</div>

Responsive Container

Responsive Container

This container adjusts its max-width based on screen size:

  • Mobile (<640px): Full width with padding
  • Tablet (640px-1024px): 768px max-width
  • Desktop (1024px-1440px): 1200px max-width
  • Large Desktop (>1440px): 1440px max-width
