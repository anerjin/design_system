Basic Container

기본 컨테이너

This is a basic container. It centers the content and has a maximum width of 1200px. The content will be responsive and adapt to different screen sizes while maintaining proper margins.

    <p>Content inside container</p>
</div>

Responsive Container

반응형 컨테이너

Responsive Container

This container adjusts its max-width based on screen size:

  • Mobile (<640px): Full width with padding
  • Small (640px+): 640px max-width
  • Medium (768px+): 768px max-width
  • Large (1024px+): 1024px max-width
  • XL (1280px+): 1280px max-width
  • 2XL (1536px+): 1536px max-width

Properties Reference

Class Max Width Description
.container 1200px Default container
.container--sm 640px Small container
.container--md 768px Medium container
.container--lg 1440px Large container
.container--xl 1920px Extra large container
.container--fluid 100% Full width container
.container--responsive Breakpoint-based Responsive container
.container--center - Centered vertically and horizontally
.container--no-padding - Remove padding
.container--padding-[size] - Padding variations (sm, md, lg, xl)
.container-section - Container for sections (48px padding)
.container-with-sidebar - Container with sidebar layout
