Properties Reference

Class CSS Property Description
.flex display: flex Flex container
.flex--inline display: inline-flex Inline flex container
.flex--row flex-direction: row Row direction
.flex--column flex-direction: column Column direction
.flex--wrap flex-wrap: wrap Allow wrapping
.flex--justify-center justify-content: center Center horizontally
.flex--align-center align-items: center Center vertically
.flex--gap-[size] gap: [size] Gap between items
.flex__item--grow flex-grow: 1 Allow item to grow
.flex__item--shrink-0 flex-shrink: 0 Prevent shrinking
.flex__item--order-[n] order: [n] Item order
.flex__item--self-center align-self: center Align self center
