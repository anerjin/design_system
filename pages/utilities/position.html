Position Types

기본 위치 타입

`.position-*` 클래스로 기본 위치 전략을 적용합니다.

Static (기본)
Relative (top: 16px / left: 16px)
Absolute (top: 12px / right: 12px) 
<div class="position-relative">
    <div class="position-static">Static</div>
    <div class="position-relative" style="top: 16px; left: 16px;">Relative</div>
    <div class="position-absolute" style="top: 12px; right: 12px;">Absolute</div>
</div>

Fixed & Sticky

스크롤 대응 패턴

`fixed`는 뷰포트에 고정되고, `sticky`는 컨테이너 안에서만 고정됩니다.

Fixed

스크롤해도 오른쪽 상단 박스는 고정됩니다.

Fixed

Lorem ipsum dolor sit amet, consectetur adipiscing elit.

Vivamus luctus urna sed urna ultricies ac tempor dui sagittis.

Nullam pharetra nulla ac diam. Quisque semper justo at risus.

Integer in mauris eu nibh euismod gravida.

Sticky

컨테이너 영역을 벗어날 때까지 상단에 붙어 있습니다.

Sticky Header

Etiam tempor. Ut ullamcorper, ligula eu tempor congue.

Aenean fermentum, elit eget tincidunt condimentum.

Integer nec odio. Praesent libero.

Sed cursus ante dapibus diam.

Reference Table

클래스 요약

Class CSS Property Description
.position-[static|relative|absolute|fixed|sticky] position 위치 전략 설정
.top-[0|50|100] top 상단 위치 지정
.right-[0|50|100] right 우측 위치 지정
.bottom-[0|50|100] bottom 하단 위치 지정
.left-[0|50|100] left 좌측 위치 지정
.inset-[0|x|y] inset 네 방향 동시 지정
.translate-center(-x|-y) transform 요소 중심 이동
.z-[0|10|20|30|40|50] z-index 쌓임 순서
.float-[left|right|none] float 플로트 방식
.clearfix clear 플로트 초기화
