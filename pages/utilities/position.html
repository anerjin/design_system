Properties

Class CSS Property Description
.position-static position: static Default position
.position-relative position: relative Relative position
.position-absolute position: absolute Absolute position
.position-fixed position: fixed Fixed position
.position-sticky position: sticky Sticky position
.top-[0|50|100] top: [value] Top position
.bottom-[0|50|100] bottom: [value] Bottom position
.left-[0|50|100] left: [value] Left position
.right-[0|50|100] right: [value] Right position
.inset-[0|x|y] inset: [value] All sides position
.z-[0|10|20|30|40|50] z-index: [value] Stack order
.float-[left|right|none] float: [value] Float element
.clearfix Clear floats Container for floats
